# 既知基層解釈参照｜地図

*役割：既知の聴覚・身体・知覚・認知系の知見を、RDL音楽の基層候補へ直結せず、参照基準点として整理する。*  
*状態：DRAFT v0.1*

## ■ 0. 範囲

本フォルダーは、人間の基層を完成モデルとして記述しない。

```text
既知基層解釈参照
  = 既知の聴覚・身体・知覚・認知系知見を
    RDL音楽のB / Γ / M_B候補 / ξへ読むための参照辞書
  ≠ 基層そのもの
  ≠ 人間知覚の完成理論
  ≠ 神経科学・聴覚科学の教科書再記述
  ≠ RDL Core
  ≠ RDL側の検証結論
```

ここで扱う既知概念は、RDL側の `B_base / Γ_base / M_B^base候補` を仮設するための参照点である。既知概念の名前を置いたことをもって、基層M_Bが確定したとは扱わない。

## ■ 1. 位置づけ

`30_既知音楽理論参照` が既存音楽理論の記述体系を参照する場所であるのに対し、本フォルダーは、物理状態差と人間側状態差の間にある変換関係を読むための既知基層系の参照場所である。

```text
物理側の観測層
  ↓
50_既知基層解釈参照
  ↓
B_base / Γ_base / M_B^base候補 / ξ_base の仮設
  ↓
40_中核音楽理論との接続検査
```

ただし、この流れは自動パイプラインではない。既知知見は参照基準点であり、RDL側の基層候補は、BとΓを明示した独立検査を経て初めて候補化される。

## ■ 3. 初期の参照軸

初期段階では、次の軸だけを置く。

```text
F_device / I_human / F_human の非同一性
時間分解能・時間的統合
可聴帯域・入力制約
差の検出・弁別
まとまり・分離
周期・反復への応答
注意・文脈によるB / Γ選択への影響
```

これらは基層M_Bの確定項目ではない。既知概念をどのB・Γで読むかを検査するための参照軸である。

## ■ 4. 禁止補完

```text
既知の聴覚・神経・認知概念をそのまま基層M_Bとみなさない
基層を生得 / 後天の一軸で固定分離しない
F_deviceをF_humanと同一視しない
物理側で検出された差を、そのまま知覚差とみなさない
知覚差を、そのままlearned音楽構造上の差とみなさない
既知知見をRDL固有の検証結論として主張しない
参照基準点をCoreへ昇格しない
```

## ■ 5. 運用

各文書は、既知概念そのものの網羅ではなく、RDL音楽の検証で使うための次の形へ絞る。

```text
既知概念
  ↓
RDLで読むときの候補B
  ↓
候補Γ
  ↓
M_B^base候補になりうる関係
  ↓
未回収ξ / 破断条件 / 禁止補完
```

参照需要が生じた時点で、可聴帯域、時間統合、弁別、音のまとまり、注意・文脈などを個別文書へ分ける。
