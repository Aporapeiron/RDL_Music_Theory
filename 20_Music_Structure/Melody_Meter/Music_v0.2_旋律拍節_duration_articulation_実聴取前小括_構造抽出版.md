## 1. 抽出主題

duration articulation系列を、実聴取前に閉じられる構造命題と、実聴取まで保留する命題へ分ける。

```text
structural closure
  ≠ actual listening closure
```

## 2. Music Core v0.2へ返せる命題

```text
same onset positions
  ≠ same melodic-metric state

duration articulation:
  relation between neighboring events
  not merely a rendering parameter

primary intervention:
  note duration change

entailed relation:
  gap / connection / overlap
  and, for overlap, local vertical simultaneity
```

## 3. 保留命題

```text
actual staccato perception
actual tenuto perception
actual legato perception
continuity vs harmonic blur
effect of local vertical simultaneity on melodic identity
```

これらはdevice-side fixtureから直接確定しない。

## 4. 再出現したMusic側の型

```text
C6 / Am7:
  bass intervention
  -> register relation change

duration articulation:
  duration intervention
  -> gap / overlap relation change
  -> possible local vertical simultaneity
```

ここから、Music側では次の候補を保持する。

```text
primary intervention
+ entailed relational changes
```

ただし、これはまだMusic内で再出現した候補であり、汎用原理として確定しない。

## 5. 停止線

```text
pre_listening_closure_is_not_actual_listening_observation
duration_thresholds_are_fixture_parameters_not_universal_articulation_constants
primary_duration_intervention_is_not_identical_to_entailed_vertical_overlap
local_vertical_overlap_is_not_harmonic_state_commitment
do_not_extend_by_micro_duration_sweep_before_actual_listening
```

## 6. 次段

duration値をさらに刻むのではなく、別のMusic対象へ移す。

```text
melody phrase / motif memory
or
timbre / attack
```

この小括は、duration articulation系列を実聴取前fixtureとして閉じ、次のMusic対象へ移るための停止線である。
