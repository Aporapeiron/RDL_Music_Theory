## 1. 抽出主題

motif memory系列を、実聴取前に閉じられる構造命題と、実聴取まで保留する命題へ分ける。

```text
structural closure
  ≠ actual listening closure
```

## 2. Music Core v0.2へ返せる命題

```text
same motif material
  ≠ same motif-memory candidate state

return start time:
  derives return gap / absence interval
  derives return phase under fixed meter

absence interval:
  not identical to sounding intervening material
  not identical to total acoustic silence

intervening material identity:
  can change while return start, gap, and phase are held
```

これらはdevice-side fixture上の分離であり、人間が実際にmemory / refrainとして聴取したことを意味しない。

## 3. 保留命題

```text
actual confirmation / echo perception
actual refrain / answer / recollection perception
silent gap vs sounding filler effect on motif retention
offphase return as interruption / compression / syncopated return
contrast before return effect on perceived return strength
E / H / theta / xi assignment after actual listening
```

これらはactual listening observationなしにCore命題へ返さない。

## 4. 再出現したMusic側の型

```text
duration articulation:
  primary duration intervention
  -> gap / overlap relation

motif memory:
  return start intervention
  -> absence interval / return phase
  -> sounding or non-sounding intervening condition
```

ここから、Music側では次の候補を保持する。

```text
one preserved material can keep identity at the material layer
while candidate state changes through temporal relation placement
```

ただし、これはまだMusic内で再出現した候補であり、汎用原理として確定しない。

## 5. 停止線

```text
pre_listening_closure_is_not_actual_listening_observation
same_motif_material_is_not_same_memory_candidate_state
return_phase_is_not_independent_under_fixed_meter
melodic_material_silence_is_not_total_acoustic_silence
meter_reference_continuity_is_a_fixture_condition_not_human_meter_confirmation
motif_return_candidate_is_not_actual_refrain_perception
do_not_extend_motif_memory_by_more_return_variants_before_actual_listening
```
