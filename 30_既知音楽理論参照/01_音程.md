# 音程

*既知音楽理論における、二音の高さ関係の代表的な記述体系*  
*状態：DRAFT v0.1 / 参照辞書*

## ■ 定義

音程は、二つの音高の隔たりを記述する既知の音楽理論上の分類である。12平均律の半音距離だけでなく、音名の文字間隔と綴りを含めて表す。

## ■ 主な分類

```text
chromatic semitone distance
  12平均律上での半音距離

generic interval
  音名の文字を数えた度数

quality
  generic intervalと半音距離の組合せによる品質

compound interval
  1オクターブを超える音程
```

## ■ generic interval

```text
unison / second / third / fourth / fifth / sixth / seventh / octave
同度        二度      三度     四度      五度     六度     七度      八度
```

度数は両端の音名を含めて数える。たとえば`C→G`は五度、`C→A`は六度である。

## ■ quality

完全系の代表は完全・増・減、長短系の代表は長・短・増・減で記述される。

```text
perfect: unison, fourth, fifth, octave
major/minor: second, third, sixth, seventh
augmented / diminished: 上記の基準からの拡張・縮小
```

## ■ 12平均律における代表対応

| 音程 | 半音数 |
|---|---:|
| P1 | 0 |
| m2 / A1 | 1 |
| M2 / d3 | 2 |
| m3 / A2 | 3 |
| M3 / d4 | 4 |
| P4 / A3 | 5 |
| A4 / d5 | 6 |
| P5 / d6 | 7 |
| m6 / A5 | 8 |
| M6 / d7 | 9 |
| m7 / A6 | 10 |
| M7 / d8 | 11 |
| P8 | 12 |

同じ半音数には、綴りにより複数の音程名が対応し得る。

```text
C4 → G4    = P5
C4 → A𝄫4  = d6
```

両例は12平均律上では同じ7半音だが、音名上の度数が五度と六度で異なるため、音程名も異なる。

## ■ 注意

音程名は周波数比や半音数だけから一意には定まらない。綴り、調律、上行・下行の扱い、文脈によって、同じ物理音高関係への記述は分岐し得る。
