## 0. 目的

本書は、Music検証から抽出された旧 `T2候補` を、新T0/T1基準で再分類するための入口である。

旧3398工程および関連する構造抽出文書は、削除・一括移動しない。これらはMusic検証から汎用構造候補が発見された履歴資料として保持する。

ただし、新基準では次を採用する。

```text
Selection ≠ T2
Metabolic Runtime全体 ≠ T2確定
candidate lifecycle全体 ≠ T2確定
```

---

## 1. 再分類先

```text
旧T2候補
  ↓
T1工程
T2汎用検査道具
Music固有Selection基準
Music↔汎用fixture
historical evidence
```

### T1工程

Probe、Expansion、Inspection、Selection、Reconstruction そのものに属する形成経路。

```text
例:
  inputをBで切り出す
  差分列を取得する
  候補構造群を展開する
  再構成へ戻す
```

### T2汎用検査道具

SelectionやInspectionに利用される交換可能な検査・評価・比較道具。

```text
例:
  durability check
  consistency check
  loss criterion evaluator
  comparison metric
  stress test harness
```

### Music固有Selection基準

Music対象を扱うために必要な判断基準・許容損失・聴取上の停止線。

```text
例:
  same pitch-class setを保存するか
  contourを保存するか
  meter phaseを保存するか
  F_deviceとF_listenerを分けるか
  actual listeningを保留するか
```

### Music↔汎用fixture

Music入力・Music出力と、汎用検査道具候補を接続する検証足場。

```text
例:
  C6/Am7 relation fixture
  melody-meter fixture
  motif-memory fixture
  timbre/attack fixture
```

### historical evidence

工程番号列、旧文書名、旧分類名、当時の抽出順序。

```text
例:
  86〜127
  179〜228
  399〜3398
  Metabolic Runtime第一圧縮
  candidate lifecycle map
```

## 3. Music側の停止線

Music本線では、汎用状態遷移だけを目的にした新規長大工程列を原則増やさない。

Music側で続けるべき作業は次である。

```text
音楽対象を置く
Bを置く
対象側SILN_music / W_musicを抽出する
入力作用EFPを分ける
自己側M_Bを明示する
structural prediction / perceptual hypothesis / actual listening observationを分ける
生成・変形へ戻す
```
