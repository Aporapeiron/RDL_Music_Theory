# Timbre / Attack：実聴取前小括

状態：device検証小括。人間聴取は未記録。
対象：既存Timbre / Attack、固定ゲイン比較、第一音RMS一致補助比較。

## 今回の到達点

同じencoded pitch / onset / duration / note orderを持つC4 E4 G4 C5について、attack、調波profile、transient noiseを個別に変えた。元の複合条件は単独効果の証拠に含めない。

| 比較 | 波形から確認したこと | 聴取待ち |
|---|---|---|
| attack短縮 | 差は各音の開始後0.09秒内。plateauは0.240秒から0.322秒へ変化 | 発音の硬さ、知覚上の開始時刻 |
| 調波追加・固定ゲイン | 第一音RMSが約0.144344から0.090702へ低下 | 音色差と音量差の寄与 |
| noise追加 | PCM差は各音の開始後0.045秒内。調波係数は同じ | noiseを聞き分けられるか |
| 調波追加・RMS補助 | 一定ゲイン1.591418919で第一音RMS誤差は約-2.30e-8 | RMS条件を変えても音色差を感じるか |

固定ゲイン比較では4単独音源と6正逆順音源、RMS補助では3音源を用意した。すべて実聴取観測はnull。正逆順の提示は盲検や履歴効果除去を意味しない。

## 保存条件の限界

第一音RMSを揃えても、フレーズ全体のピークは基準0.239998、補助版0.281533と異なる。残り3音のRMSは個別調整していない。今回の測定では近い値だが、一般的な一致条件として扱わない。

したがって「音量を保存した」と一語で記録せず、固定ゲイン、第一音RMS、ピーク、基音振幅、知覚音量のうち何を制御・測定したかを書く。RMS補助は元の一次介入にゲイン介入を加えた比較である。

## Musicへ返す候補

同じ符号化された音列でも、各音の内部形成条件は異なる波形を作る。attack変更にはplateau・エネルギー配分の変化が、調波追加にはrendererの正規化による振幅変化が伴った。

これはMusic内部で保持してきた「一次介入と、その実現に伴う関係変化を併記する」という扱いの適用例である。人間が異なる音楽状態として聞いたことや、音色の普遍的な重みを確定した結果ではない。

[Music構造抽出](../../20_Music_Structure/Timbre_Attack/実聴取前小括_構造抽出.md)に、保存条件をMusicの分析・変形へ返す範囲をまとめる。

聴取では再生条件・提示順・反復回数を残し、音色差、音量差、開始時刻、旋律の同一性について自由記述する。「差が分からない」「判定不能」も記録する。記録は生成manifestとは別ファイルに置く。

その後、特定の自己側M_Bによる予測と後続解釈を対応づけてEを検討する。未吸収部分Hとθの判定、有限Bに伴う未回収関係ξの記述は別々に行う。実聴取報告だけから自動的にMusic Coreを更新しない。

## 停止線と次の対象

device検証として一区切りとし、実聴取欄を開いたまま保持する。追加のattack刻み、noise量、RMS正規化方式の探索は、聴取結果または新しい音楽的問いが出た時に再開する。

次のMusic対象候補は、同じ旋律・和声材料に対する声部配置である。二声の音域配置と交差が、各声部の追いやすさや旋律の帰属にどう関係するかを、既存の声部進行資産から小さな比較へ落とす。今回はその新実験には未着手。
