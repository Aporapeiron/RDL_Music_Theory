# Melody Transformation：移調と反行

状態：最初のdevice検証。人間の同一性判断は未記録。

## 問いと境界

短い単旋律を変形するとき、保存する音程関係と変更する音程関係を明示して別の旋律を生成する。今回は12TETの半音単位を用い、調内で音階の段を反転する操作とは区別する。声部追跡や音色別の聞き分け課題は持ち込まない。

原形はC4 D4 E4 G4 F4 E4 D4 C4。8音の自作fixtureで、各開始を1拍間隔、各音価を0.82拍、1拍を0.5秒とする。

| 条件 | MIDIへの操作 | 生成音列 |
|---|---|---|
| 原形 | n | C4 D4 E4 G4 F4 E4 D4 C4 |
| 移調 | n + 5 | F4 G4 A4 C5 Bb4 A4 G4 F4 |
| 反行 | 120 - n | C4 Bb3 Ab3 F3 G3 Ab3 Bb3 C4 |

反行軸はC4（MIDI 60）。綴りは読みやすさのための表示で、コードの操作対象はMIDI半音値。ここから調・和声機能を自動確定しない。

## 保存と変化

全条件でonset・duration・イベント順序・隣接音程の絶対値を保存する。移調は符号付き音程列と輪郭を保存する。反行は非ゼロの音程の符号を反転する。

原形の音程列は +2,+2,+3,-2,-1,-2,-2。反行では -2,-2,-3,+2,+1,+2,+2。移調を戻す操作と二度の反行で、符号化された元の音列へ戻ることを検査する。

一次介入は音高写像であり、声域・絶対周波数・音高クラス内容の変化を伴う。合成設定は既存soft sineを再利用する。同一設定から知覚音色や音量の一致を推論しない。

音程の保存・反転、逆操作、音声の読み戻しとクリッピングなしを検査する。今回の成果は、保存関係を指定して変形音を生成できたこと。人間に同じ旋律や同じ主題として感じられるかは別の問いとして残す。
