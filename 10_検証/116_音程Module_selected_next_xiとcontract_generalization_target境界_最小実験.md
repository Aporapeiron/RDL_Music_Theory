*対象：115で選ばれた`xi_interval_module_contract_generalization`を、音程Module計画へ接続する境界*  
*状態：DRAFT v0.1 / 音楽系優先*  
*実装：`10_検証/interval_module_contract_generalization_target.py`*

## ■ 0. 検証目的

115で得たselected next ξを、汎用方法論側へ進めず、音程Module本体の契約一般化へ戻す。

```text
selected next ξ
+ external interval module plan reference
↓
contract generalization target candidate
↓
contract clauseは未生成
```

## ■ 1. 非同一性

```text
selected next ξ
≠ module plan reference
≠ contract generalization target
≠ contract clauses
```

116では、次に開くξを音程Module計画へ向けるtarget候補までを作る。
