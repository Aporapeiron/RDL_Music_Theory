# 検証記録：声部進行・selected targetから具体音実現境界

*対象：43で生じたselected targetを、既存14の具体音実現構造へ接続する条件*  
*状態：DRAFT v0.1 / 43の後続接続検証*  
*実装：`10_検証/voice_leading_selected_target_realization_boundary.py`*

---

## ■ 0. 検証目的

43では、function annotation候補からtarget候補集合を生成せず、外部入力されたtarget候補集合と明示された`Γ_select`によってselected targetが生じることを確認した。

44では、新しい声部進行理論を作らない。

43のselected targetを、既存14の

```text
target degree
  ↓ B_realization
候補オクターブ・声部範囲
  ↓ Γ_spelling
綴り付き候補集合
  ↓ B_range_projection
範囲通過候補
  ↓ Γ_ordering
許容候補対
  ↓ Γ_select
具体的target
```

へ接続できるかを見る。

ここで確認するのは、次である。

```text
selected target
  ≠ target degree plan
  ≠ concrete pitch realization
```

---

## ■ 1. 固定する最小入力

43から次を受け取る。

```text
selected target = C major
```

ただし、`C major`というselected targetからtarget degreeや具体音を生成しない。

今回は外部fixtureとして、次のtarget degree planを与える。

```text
target degree plan:
  context = C major
  lower target degree = 3
  upper target degree = 1
```

これは14の `A4 representative realization` へ接続するための固定写像である。

---

## ■ 2. 接続する既存構造

具体音実現には、既存の `10_検証/degree_to_pitch_realization.py` を使う。

```text
build_requests()
  ↓
A4 representative realization
  ↓
realize_pair()
```

44では、既存14の実現器を再実装しない。

接続だけを確認する。

```text
selected target from 43
  ↓ external target degree plan
existing 14 realization request
  ↓ realize_pair()
concrete target pair
```

## ■ 3. 最小ケース

### 3.1 selected target

```text
dominant_candidate

  ↓

これは43で確認済みの経路である。

### 3.2 external target degree plan

C major selected target
  + external fixture
  ↓
lower target degree = 3

```

この変換はselected targetから自動生成しない。

target degrees = 3 / 1

generated candidates:
  lower = E3 / E4 / E5

## ■ 5. Module責務の確認

今回の接続は、次のように分かれる。

```text
和声機能Module / 43:
  selected target = C majorを渡す

target degree境界:
  外部fixtureとして3 / 1を渡す

声部進行Module / 14:
  B_realizationとΓにより具体音候補を生成・選択する
```

44は、43のselected targetを既存14へ接続する検証であり、声部進行Moduleを新設しない。

---

## ■ 6. まだ言えないこと

今回の検証から、次は言えない。

```text
selected targetからtarget degree planが自動生成できること
C major targetが常に3 / 1のtarget degreeを持つこと
target degreeから具体音が一意に決まること
E4-C5が一般的に正しい声部進行であること
voice leading後にnext key contextが決まること
```

target degree planはfixtureであり、具体音実現は既存14の限定された実現規則に依存する。

これらは未解決ξとして残す。

---

## ■ 7. 暫定結論

44では、43で生じたselected targetを、既存14の具体音実現構造へ接続できることを確認した。

```text
selected target = C major
  ↓ external target degree plan
target degrees = 3 / 1
  ↓ existing 14 realization
selected concrete target = E4-C5
```

ただし、この接続は自動生成ではない。

```text
selected target
  ≠ target degree plan
  ≠ concrete pitch realization
```

したがって、42〜44で次の分離が確認された。

```text
function annotation
  ≠ target candidate generation
  ≠ target selection
  ≠ target degree planning
  ≠ concrete pitch realization
```

次の検証では、44の接続後に、voice leading resultをnext key/context interpretationへ直結しない条件を見る。
