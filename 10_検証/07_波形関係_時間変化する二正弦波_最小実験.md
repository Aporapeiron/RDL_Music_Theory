# 検証記録：時間変化の中で保存される波形関係

*対象：音名・コード・調性より下位の波形関係*  
*状態：DRAFT v0.1 / RDL音楽_Coreへの追加前の検証*  
*実装：`10_検証/time_varying_two_sine_wave_relations.py`*

---

## ■ 0. 検証目的

06では、固定周波数の2成分について、

```text
ratio_preserved
≠
short_recurrence_candidate
```

を分離した。ただし、06の`ratio_preserved`は、

```text
f1 = constant
f2 = constant
```

という既知成分モデルから構成上成立していた。今回は成分の絶対周波数を時間変化させ、

```text
絶対値が変化する
≠
関係構造が壊れる
```

を、2成分のまま検査する。

今回の主判定は短周期再帰ではない。短周期再帰の候補化は06に残し、時間変化する関係保存と混同しない。

```text
f1(t), f2(t)
↓
周波数値の保存
周波数比の保存
↓
保存関係ごとのM_B候補
```

---

## ■ 1. 入力と波形生成

各成分の瞬時周波数を時間関数として与える。

```text
f1(t)
f2(t)
```

波形は、周波数値をそのまま`sin(2π f(t)t)`へ代入せず、位相を積分して生成する。

```text
phase_i(t) = 2π ∫_0^t f_i(τ)dτ
F(t) = sin(phase_1(t)) + sin(phase_2(t))
```

線形周波数の場合は、

```text
f(t) = a + bt
∫_0^t f(τ)dτ = at + 1/2 bt²
```

となる。周波数軌道は既知モデルであり、未知波形から周波数を推定するスペクトル解析ではない。モデルから得た関係判定と、そこから生成した実サンプル列`F(t)`を分けて記録する。

---

## ■ 2. BとΓ

観測境界`B`は次の通りとする。

```text
B_wave_observation:
  duration_s      = 4.0
  sample_rate_hz  = 10000
```

関係抽出規則`Γ_ratio_time`は次の通りとする。

```text
Γ_ratio_time:
  ratio_tolerance         = 1e-9
  frequency_tolerance_hz  = 1e-9
```

比の保存は、観測窓内の最大偏差で判定する。

```text
r(t) = f2(t) / f1(t)
r0   = r(0)
max_ratio_deviation = max_t |r(t) - r0|
```

```text
max_ratio_deviation <= ratio_tolerance
↓
ratio_preserved
```

絶対周波数は各成分を別々に見る。

```text
max_f1_deviation_hz = max_t |f1(t) - f1(0)|
max_f2_deviation_hz = max_t |f2(t) - f2(0)|
```

したがって、`f1`だけが保存され、`f2`は変化するケースも記述できる。

---

## ■ 3. 3ケース

### Case A：固定値・固定比

```text
f1(t) = 100
f2(t) = 150
```

絶対周波数も比`3/2`も保存される。

### Case B：値は動くが比は保存

```text
f1(t) = 100 + t
f2(t) = 1.5(100 + t)
```

```text
絶対周波数：f1・f2とも変化
比          ：常に3/2
```

例えば4秒間では、概念的に、

```text
100 → 104
150 → 156
```

と両方が動く。それでも、

```text
f2(t) / f1(t) = 3/2
```

は保存される。これが今回の中心ケースである。

### Case C：一方は固定、一方は変化

```text
f1(t) = 100
f2(t) = 150 + t
```

`f1`の値は保存されるが、`f2`の値は変化し、比も時間とともに変化する。

---

## ■ 4. 判定軸

| 軸 | 意味 |
|---|---|
| `f1_value_preserved` | `f1(t)`が初期値から観測境界内で変化しない |
| `f2_value_preserved` | `f2(t)`が初期値から観測境界内で変化しない |
| `ratio_preserved` | `f2(t)/f1(t)`が初期比から観測境界内で変化しない |
| `waveform_peak` / `waveform_rms` | 積分位相から生成した実サンプル列の補助記録 |

これらは同じ安定性の別名ではない。

```text
Case B:
  f1_value_preserved = false
  f2_value_preserved = false
  ratio_preserved    = true
```

絶対値は保存されなくても、関係は保存されうる。

---

## ■ 5. 結果の読み方

| ケース | `f1`値 | `f2`値 | 比 | 解釈 |
|---|---:|---:|---:|---|
| A | 保存 | 保存 | 保存 | 値も比も保存 |
| B | 非保存 | 非保存 | 保存 | 値は動くが比は保存 |
| C | 保存 | 非保存 | 非保存 | 一方の値だけ保存、比は変化 |

Case Bは、`M_B`候補を静止した値の集合だけとして扱うことへの反例になる。

```text
M_B候補
≠
値そのものが動かないこと
```

より弱い、しかし重要な候補として、

```text
M_B候補
=
変化の中でも保存される関係
```

を置ける。

ただし、これはまだRDL音楽_Coreの基本原理ではない。既知の時間軌道を与えた単一実験の結果であり、別の波形・観測境界・関係抽出規則で再現する必要がある。

---

## ■ 6. RDL上の位置づけ

06の構造を時間方向へ拡張すると、

```text
F_wave(t)
↓ B_wave_observation
f1(t), f2(t)
↓ Γ_ratio_time
保存関係の分離
├─ f1_value_preserved
├─ f2_value_preserved
└─ ratio_preserved
↓
保存関係ごとのM_B候補群
```

となる。

これは、

```text
絶対値の変化
≠
関係構造の変化
```

を物理波の最小例で扱うものである。

Case Bでは、周波数の絶対位置は移動している。しかし、2成分の比という`W`の一部は保存される。このとき「同じ構造」と呼べる範囲が、値ではなく関係に置かれる可能性がある。

一方で、どの関係を保存関係として採用するかは`Γ`に依存する。比を見れば保存されるCase Bも、差周波数や固定値を見れば変化している。

したがって、

```text
何が同じか
```

は、対象だけでなく、観測する`W`と抽出規則`Γ`の組み合わせで決まる。

## ■ 7. 今回まだ確定していないこと

```text
未知波形からf1(t)・f2(t)を推定する方法
実音の部分音が時間変化するときの関係抽出
周波数比以外の保存関係の統合方法
時間変化する波形に対する短周期再帰の定義
知覚上の音高・音程がどの保存関係を圧縮するか
```

特に、Case Bの`ratio_preserved`は、今回の既知軌道モデルから観測した結果である。実波形から比を推定して発見したわけではない。

## ■ 8. 暫定結論

```text
固定周波数モデルでは、ratio_preservedは構成上成立する。
時間変化する周波数軌道では、比の保存を軌道上で個別に判定できる。
絶対周波数が変化しても、比が保存されるケースを2成分で作れる。
一方の成分だけが固定され、比が崩れるケースも分離して記述できる。
```

したがって、現段階の有力な暫定候補は、

```text
M_B候補
=
B内で保存される関係の束
```

である。

ここでいう「束」は、単一の安定度ではなく、`f1`値、`f2`値、比、差周波数、位相、再帰など、複数の保存軸を並列に保持するという意味である。
