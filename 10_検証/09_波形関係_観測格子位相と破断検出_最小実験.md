# 検証記録：観測格子の開始位相と短時間の関係破断

*対象：音名・コード・調性より下位の波形関係*
*状態：DRAFT v0.1 / RDL音楽_Coreへの追加前の検証*
*実装：`10_検証/sampling_phase_ratio_break.py`*

---

## ■ 0. 検証目的

08では、同じ短時間の比破断が、sample_rateの違いによって検出されたり見落とされたりした。今回はsample_rateを固定し、観測格子の開始位相だけをずらす。

```text
同じ対象
同じduration
同じsample_rate
同じΓ_point_ratio
観測格子の開始位相だけが異なる
```

これにより、観測可能性が分解能だけではなく、観測格子をどこに置いたかにも依存することを確認する。

---

## ■ 1. 08から引き継ぐモデル

既知の成分モデルは08と同じである。

```text
f1(t) = 100 Hz

通常：       f2(t) / f1(t) = 1.5
破断区間：   f2(t) / f1(t) = 1.6

1.23425 s ≤ t < 1.23475 s
```

破断の長さは0.5 msである。モデル上の破断は、観測格子の配置にかかわらず存在する。

08で分離した軸をそのまま使う。

```text
model_ratio_break_present
break_intersects_observation_window
sampled_break_detected
observed_ratio_preserved
```

`model_ratio_break_present`は、既知モデルに破断が組み込まれていることを表す。これは観測結果ではない。

---

## ■ 2. 観測境界Bと判定規則Γ

観測時間とsample_rateは両ケースで固定する。

```text
B:
  duration_s      = 2.0
  sample_rate_hz  = 1000
```

サンプル格子は次で表す。

```text
t_n = sampling_phase_s + n / sample_rate_hz
```

ただし、`sampling_phase_s`は1サンプル間隔の範囲内に置く。今回の2ケースは次のとおりである。

| ケース | `sample_rate_hz` | `sampling_phase_s` | 破断区間内の点 |
|---|---:|---:|---:|
| phase 0 | 1000 | 0 ms | 0点 |
| phase 0.5 ms | 1000 | 0.5 ms | 1点 |

判定規則は08と同じ`Γ_point_ratio`であり、サンプル時点での既知比を初期比と比較する。

```text
r_n = f2(t_n) / f1(t_n)
r_0 = f2(t_0) / f1(t_0)
max_n |r_n - r_0|
```

今回、変えているのは`sampling_phase_s`だけである。

---

## ■ 3. 結果

### phase 0

破断区間は1.23425〜1.23475秒である。1 kHz・位相0の格子には1.234秒と1.235秒の点が入るが、破断区間の内側には点がない。

```text
model_ratio_break_present           = true
break_intersects_observation_window = true
sampled_break_count                 = 0
sampled_break_detected              = false
observed_ratio_preserved            = true
```

この`observed_ratio_preserved`は、連続時間で比が保存されたという意味ではない。今回の格子と`Γ_point_ratio`では、破断を検出しなかったという意味である。

### phase 0.5 ms

格子を0.5 msずらすと、1.2345秒の点が破断区間へ入る。

```text
model_ratio_break_present           = true
break_intersects_observation_window = true
sampled_break_count                 = 1
sampled_break_detected              = true
observed_ratio_preserved            = false
```

sample_rateは同じ1000 Hzであり、判定規則も同じである。それでも、開始位相を変えるだけで観測結果が変わる。

---

## ■ 4. 何が変わったか

```text
sample_rate       同じ
duration          同じ
対象モデル        同じ
Γ_point_ratio     同じ

sampling_phase    異なる
観測結果          異なる
```

したがって、今回の結果は次を示す。

```text
分解能だけ
≠
観測条件Bの全体
```

観測格子の配置もBの一部である。

```text
B
├─ 観測時間
├─ sample_rate
└─ sampling_phase
```

同じsample_rateでも、局所的な破断と格子の位置関係が変われば、観測された関係記述は変わる。

---

## ■ 5. RDL上の位置づけ

08の粗いBでは、破断は「観測点では破れなかった関係」として残った。09では、その同じsample_rateのまま格子をずらすと、破断が回収される。

```text
対象側の短時間破断
        ↓
B：時間窓・分解能・観測格子の配置
        ↓
Γ_point_ratio
        ↓
検出された破断 / 未検出の破断
```

したがって、現段階の`M_B候補`はさらに操作的に、次のように記述できる。

```text
M_B候補
=
現在のBとΓ_point_ratioで
破断が検出されず、保存として扱える関係
```

ここで、phase 0の未検出部分を、破断の内容まで分かった`ξ`と同一視してはいけない。正確には、

```text
phase 0のB
→ 破断を回収できない領域が残る
→ その未回収領域をξとして保持できる

phase 0.5 msのB
→ 同じモデル上の破断の一部を回収する
```

である。`ξ`はこの実験が直接計算する量ではなく、BとΓによって回収されなかった余白を記述する位置づけに留める。

---

## ■ 6. 今回まだ確定していないこと

```text
未知波形から局所的な比破断を推定する方法
波形の位相痕跡を用いる別のΓによる再検出
全てのsampling_phaseに対する検出確率
破断幅・sample_rate・sampling_phaseの一般関係
聴覚上の短時間破断の知覚可能性
```

今回の結論は、あくまで既知の瞬時周波数軌道を`Γ_point_ratio`で点サンプリングした結果に限られる。

---

## ■ 7. 暫定結論

```text
同じ対象・同じsample_rateでも、sampling_phaseが変わると破断検出が変わる。
phase 0では、今回のΓ_point_ratioは破断を見落とす。
phase 0.5 msでは、同じΓ_point_ratioが破断を検出する。
```

したがって、08・09を合わせた暫定的な記述は、次のようになる。

```text
M_B候補
=
対象の絶対属性そのものではなく、
B（観測時間・分解能・格子配置）とΓのもとで
破断を受けずに残った記述
```
