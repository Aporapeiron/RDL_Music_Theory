# 検証記録：C6とAm7

*RDL音楽_Coreの最小実例*  
*対象：同一音集合と異なる安定構造*  
*状態：DRAFT v0.1*

---

## ■ 0. 検証目的

C6とAm7は、12平均律上では同じ音集合を持つ。

```text
C6  = C - E - G - A
Am7 = A - C - E - G
```

しかし、同じ音集合であることは、同じ音楽構造であることを意味しない。

この実例では、次を確認する。

```text
同じ音集合を、何が別のM_Bとして保つのか。
低音・配置・履歴・次の遷移が、BとWにどう作用するのか。
どの変化が単なるボイシング変更で、どの変化が構造変化になるのか。
```

ここでC6とAm7の名称は、分析結果を圧縮して呼ぶためのラベルとして使う。最初から名称を実体とはみなさない。

---

## ■ 1. 前提となる音素材

### 1.1 音集合

```text
P = {C, E, G, A}
```

この集合だけでは、C6とAm7のどちらが現在の安定構造かは決まらない。

### 1.2 例A：Cを低音に置く

```text
低音：C
上部：E - G - A
```

関係の圧縮ラベルはC6となる。

```text
M_B^A ≈ Cを低い基準として、E・G・Aを上部関係に置く構造
```

### 1.3 例B：Aを低音に置く

```text
低音：A
上部：C - E - G
```

関係の圧縮ラベルはAm7となる。

```text
M_B^B ≈ Aを低い基準として、C・E・Gを上部関係に置く構造
```

音集合は保存されているが、低音を含む関係の重みが変わっている。

---

## ■ 2. 境界Bの設定

この検証では、次の境界を同時に見る。

```text
B_pitch  ：使用される音高・音集合
B_bass   ：低音を基準とする関係
B_time   ：音が置かれる拍・長さ・前後関係
B_context：直前・直後の音楽状態
```

`B_pitch`だけを切り出せば、C6とAm7は同一に見える。

`B_bass`と`B_context`を含めると、異なる安定構造として分岐しうる。

したがって、音楽的な同一性は、単一のBから自動的に決まらない。

```text
Bの切り方
    ↓
何を同一とみなせるか
    ↓
M_Bの候補
```

---

## ■ 3. 関係Wの分解

この実例で最低限見る関係は次の通り。

| 関係 | 何を見るか | C6とAm7での差 |
|---|---|---|
| `W_pitch` | 音集合・音高間隔 | 集合は同じ |
| `W_bass` | 低音と上部音の関係 | CまたはAが基準になる |
| `W_register` | 音域・配置 | 同じ音集合でも重心が変わる |
| `W_time` | 発音順・長さ・拍位置 | どの音が先に現れるかが変わる |
| `W_context` | 前後の和声・旋律との接続 | 次状態候補を変える |
| `W_voice` | 各声部の移動 | 共通音の保存や低音の移動が現れる |

`W_pitch`だけでは差は小さい。しかし、`W_bass`、`W_context`、`W_voice`が加わると、同じ集合から複数のM_Bが成立する。

---

## ■ 4. 状態記述

### 4.1 C6として安定している状態

```text
B_t = {pitch, bass, time, context}

M_B^C6 = {
  Cを低音の基準とする,
  E・G・Aを上部へ配置する,
  Cを中心とした関係を維持する
}

W^C6 = {
  W_pitch   : {C, E, G, A},
  W_bass    : C → {E, G, A},
  W_register: Cを低く、上部音を相対的に高く置く,
  W_context : 直前までCを基準として聞かせる
}
```

### 4.2 Am7として安定している状態

```text
B_t = {pitch, bass, time, context}

M_B^Am7 = {
  Aを低音の基準とする,
  C・E・Gを上部へ配置する,
  Aを中心とした関係を維持する
}

W^Am7 = {
  W_pitch   : {A, C, E, G},
  W_bass    : A → {C, E, G},
  W_register: Aを低く、上部音を相対的に高く置く,
  W_context : 直前までAを基準として聞かせる
}
```

同じ`W_pitch`を持っていても、`W_bass`と`W_context`が異なれば、別のM_Bが安定しうる。

---

## ■ 5. FとE

### 5.1 F：実際に現れた作用

たとえば、C6の状態からAを低音へ移す。

```text
F = {
  上部のC・E・Gをおおむね保存する,
  低音をCからAへ移す,
  Aを低い位置で発音する
}
```

### 5.2 E：現在構造との差

直前のM_BがC6として安定していた場合、主なEは音集合全体ではなく、低音関係に現れる。

```text
E ≈ W_bassにおける、C基準からA基準へのずれ
```

これは「間違った音」ではない。

```text
M_B^C6
   ↓ 低音だけを変更
E：低音関係の逸脱
   ↓ 反復・周辺関係・時間経過
M_B^Am7の候補
```

一方、最初から低音がなく、上部音だけが同時に鳴る場合、C6とAm7のどちらかを確定できないことがある。

この場合、Eが大きいというより、現在のBでは複数のM_B候補が並存している。

```text
M_B^C6  ↔  M_B^Am7
       ↓
      ξ または blur
```

したがって、曖昧さと逸脱は同一ではない。

---

## ■ 6. H：時間を通過した差

C6の状態で一度だけAを低音に置き、そのままCへ戻るなら、低音関係のEは短時間で吸収される可能性がある。

```text
C6 → A bass → C6
```

この場合、Aは経過的な変化、装飾、または一時的な重心移動として聞かれうる。

反対に、Aを低音に置く時間が長く、反復され、後続関係もAを基準に組まれるなら、C6を基準とした差は持続する。

```text
C6 → A bass → A bass → Am7周辺の遷移
```

このとき、Eは単発の差ではなく、次のM_B形成へ関与する。

ここではHを「緊張」と同一視しない。

```text
H = 低音関係の差が、時間・反復・配置を通過して残した作用
```

Hが蓄積しても、必ず不快になるとは限らない。また、Hが小さくても、配置や終止位置によって構造変化が明瞭になる場合がある。

---

## ■ 7. ξ：現在の切り方で回収されないもの

上部音だけを同時に鳴らし、低音・前後関係・拍位置を隠した場合、C6とAm7の判定は確定しない。

この未確定部分を、現在のBにおける`ξ`として記録できる。

```text
観測：{C, E, G, A}
不足：低音・履歴・次状態
ξ：C6とAm7を一意に分ける関係成分
```

後から低音Aが加われば、ξの一部はAm7の構造へ回収される。逆に、Cを基準とする前後関係が明らかになれば、C6として回収される。

さらに、C6ともAm7とも異なる文脈――たとえばモードやペダルポイント――を導入すれば、二つのラベルでは足りない新しいBが必要になる可能性がある。

```text
ξ
 ↓ 別の境界設定
B_new
 ↓
M_B_new
```

## ■ 8. 状態遷移の記述

### 8.1 ボイシングだけを変える場合

Cを低音の基準として保ち、上部音の配置だけを変える。

```text
S_t(C6, close voicing)
  → change(W_register)
  → S_t+1(C6, open voicing)
```

この場合、`M_B`の中心は保存される可能性が高い。

```text
preserve(W_bass)
preserve(M_B^C6)
change(W_register)
```

### 8.2 低音を変える場合

上部音をおおむね保存し、低音をCからAへ移す。

```text
S_t(C6)
  → change(W_bass)
  → E(W_bass)
  → S_t+1(Am7候補)
```

低音変更が一時的ならC6へ戻る候補が残る。反復・持続・後続関係によっては、Am7を新しいM_Bとして安定させる。

### 8.3 低音を隠す場合

```text
S_t(C6 または Am7)
  → blur(B_bass)
  → 複数のM_B候補
```

この操作は、音集合を変えずに解釈の収束を遅らせる。

---

## ■ 9. 生成への逆利用

### 9.1 「音集合を保ったまま、重心だけを動かす」

目的を次のように置く。

```text
目的：C6として聞かれている状態を、Am7方向へ動かす
保存：上部音C・E・G、音集合
変更：低音関係、持続時間、後続関係
```

具体操作の候補は次の通り。

```text
1. C6の上部音を保つ
2. Aを低音へ導入する
3. Aを一瞬で戻さず、一定時間保持する
4. 後続音をA基準の関係へ接続する
5. 必要ならA・C・E・Gの配置を安定させる
```

### 9.2 「Am7を保ったまま、C6の色を残す」

```text
preserve(W_bass = A)
preserve(M_B^Am7)
change(W_register)
change(W_voice)
```

Aを低音に残しながら、上部のAを強調したり、Gを弱めたりすれば、同じ音集合でもAm7内の重心を変えられる。

ここで重要なのは、コード名を変更することではなく、どの関係を保存し、どの関係を変更したかを指定することである。

---

## ■ 10. 暫定結論

この実例から、少なくとも次が言える。

```text
同じ音集合 ≠ 同じM_B
低音は、音集合とは別の強い関係境界になりうる
履歴と後続関係が、同じ音を別の構造へ回収する
一時的な低音変更と、持続する構造変更は区別が必要
曖昧さは、必ずしも大きなEではない
```

また、C6とAm7の差を単一の「コードの正体」に還元する必要はない。

```text
音集合
低音
配置
発音順
時間
履歴
後続関係
```

これらの関係の組み合わせが、その時点のM_Bを形成する。

```text
低音が常に最も強い基準になるか
同じ音集合を保ったままBを切り替える条件

```
