# 検証記録：基層-learned・selected bridgeとcategory confirmation境界

*対象：selected bridge candidateを、外部confirmation条件とΓによってconfirmed learned category candidateへ昇格する境界*  
*状態：DRAFT v0.1 / 64 bridge selection controller境界検証後のcategory confirmation最小検証*  
*実装：`10_検証/base_to_learned_category_confirmation_boundary.py`*

---

## ■ 0. 検証目的

64では、同じprioritized bridge orderingでも、selection controllerを与えた場合だけselected bridge candidateが生じることを確認した。

65では、そのselected bridge candidateを固定し、confirmation evidenceと`Γ_category_confirmation`を外部に与えたときだけ、confirmed learned category candidateへ昇格することを確認する。

```text
selected bridge candidate
  + external confirmation evidence
  + Γ_category_confirmation_fixture
  ↓
confirmed learned category candidate
  ↓
selected musical interpretationは未生成
```

ここで確認するのは、selected bridge candidateがconfirmed learned categoryそのものではなく、confirmationにも別の境界が必要であることだ。

---

## ■ 1. 固定するselected bridge candidate

64で得たtop-rank controller側のselected bridge candidateを使う。

```text
selected bridge candidate:
  learned_candidate = different_pitch_relation_label_candidate
  selection_reason = selected_priority_rank_1
```

これはbridge selectionの結果であり、まだlearned categoryの確定ではない。

```text
selected bridge candidate
  ≠ confirmed learned category
```

---

## ■ 2. 外部confirmation evidence

今回はfixture用のconfirmation evidenceを外部入力として置く。

```text
external confirmation evidence:
  evidence_label = stable_label_use_fixture
  supports_candidate_label = different_pitch_relation_label_candidate
```

これはselected bridge candidateから生成しない。

```text
confirmation evidence
  ≠ generated by selected bridge candidate
```

---

## ■ 3. confirmation Γ

二つの経路を比較する。

```text
Γ_category_confirmation = None
  → selected bridge candidate remains unconfirmed
```

```text
Γ_category_confirmation_fixture
  → evidenceがselected bridge candidateを支持する場合だけ
     confirmed learned category candidateを作る
```

このΓはfixture用であり、一般的な学習・文化・音楽解釈の確定規則ではない。

---

## ■ 4. 最小ケースの比較

### 4.1 confirmation Γなし

```text
selected bridge candidate
+ external confirmation evidence
+ Γ_category_confirmation = None
↓
status = selected_bridge_unconfirmed_without_gamma
confirmed learned category candidate = None
```

### 4.2 confirmation Γあり

```text
selected bridge candidate
+ external confirmation evidence
+ Γ_category_confirmation_fixture
↓
confirmed learned category candidate
  = different_pitch_relation_label_candidate
```

ただし、selected musical interpretationは生成しない。

---

## ■ 5. 観測結果

| selected bridge candidate | confirmation evidence | Γ_confirmation | confirmed learned category candidate | selected musical interpretation |
|---|---|---|---|---|
| different label bridge | same | None | `None` | `None` |
| different label bridge | same | fixture | `different_pitch_relation_label_candidate` | `None` |

確認できたこと。

```text
same selected bridge candidate
same confirmation evidence
different Γ_category_confirmation
↓
confirmed learned category candidate appears / does not appear
```

さらに、

```text
confirmed learned category candidate
  ≠ selected musical interpretation
```

である。

---

## ■ 6. Module責務の確認

今回の接続は、次のように分かれる。

```text
Γ_bridge_selection:
  selected bridge candidateを作る

external confirmation evidence:
  confirmation用の外部条件として渡す

Γ_category_confirmation:
  selected bridge candidateとevidenceの整合を読む

musical interpretation:
  今回は未接続

中核音楽理論Module:
  今回は未接続
```

したがって、confirmationはselectionではない。また、confirmed learned category candidateは音楽解釈確定ではない。

---

## ■ 7. まだ言えないこと

今回の検証から、次は言えない。

```text
confirmed learned category candidateが一般的に正しいカテゴリーであること
confirmed learned category candidateがselected musical interpretationであること
confirmation evidenceの由来や採用条件が決まったこと
Γ_category_confirmationの由来や採用条件が決まったこと
文化差・学習差・命名体系差が説明されたこと
中核音楽理論Moduleへ接続できること
```

また、今回の`Γ_category_confirmation`はfixture用であり、一般的なcategory confirmation ruleではない。

---

## ■ 8. 暫定結論

65では、selected bridge candidateだけではconfirmed learned category candidateに昇格せず、external confirmation evidenceと`Γ_category_confirmation`を与えた場合だけconfirmationが生じることを確認した。

```text
selected bridge candidate
  + external confirmation evidence
  + Γ_category_confirmation_fixture
  ↓
confirmed learned category candidate
```

ただし、ここで停止する。

```text
confirmed learned category candidate
  ≠ selected musical interpretation
  ≠ 中核音楽理論Moduleへの接続
```

次に進むなら、confirmed learned category candidateをselected musical interpretationへ接続する境界、または中核音楽理論側の候補と照合する境界を見る。
