# 検証記録：和声機能・target候補生成規則差し替えによる候補集合分岐

*対象：同じfunction annotation candidateとkey contextでも、生成規則が変わるとtarget候補集合が変わる条件*  
*状態：DRAFT v0.1 / 46の後続検証*  
*実装：`10_検証/harmonic_function_generation_rule_variation.py`*

---

## ■ 0. 検証目的

46では、function annotation candidateの後段に、外部から与えた限定的なtarget候補生成規則を接続できることを確認した。

47では、同じfunction annotation candidateと同じkey contextを固定したまま、生成規則だけを差し替える。

```text
same function annotation candidate
  + same key context
  + different Γ_target_candidate_generation_fixture
  ↓
different generated target candidate sets
```

ここで確認するのは、生成結果がfunction annotationの属性ではなく、少なくとも次の組に依存することである。

```text
function annotation candidate
  × key context
  × Γ_target_candidate_generation_fixture
```

---

## ■ 1. 固定する入力

46と同じfunction observationを使う。

```text
G major triad
  + C major
  ↓
degree 5
  ↓
function annotation = dominant_candidate
```

今回は、function annotation candidateとkey contextを変えない。

---

## ■ 2. 差し替える生成規則

二つのfixture生成規則を用意する。

```text
Γ_A:
  name = dominant_in_c_major_tonic_and_deceptive
  output fixture = {C major, A minor}

Γ_B:
  name = dominant_in_c_major_tonic_only
  output fixture = {C major}
```

どちらもfixture用の限定規則であり、一般和声規則ではない。

---

## ■ 3. 最小比較

### 3.1 Γ_A

```text
dominant_candidate
  + C major
  + Γ_A
  ↓
generated target candidate set = {C major, A minor}
```

### 3.2 Γ_B

```text
dominant_candidate
  + C major
  + Γ_B
  ↓
generated target candidate set = {C major}
```

同じfunction annotation candidate、同じkey contextでも、生成規則が変わると候補集合が変わる。

---

## ■ 4. 観測結果

| function annotation | key context | generation rule | generated target candidates | generated by function annotation alone |
|---|---|---|---|---|
| `dominant_candidate` | `C major` | `dominant_in_c_major_tonic_and_deceptive` | `C major`, `A minor` | `false` |
| `dominant_candidate` | `C major` | `dominant_in_c_major_tonic_only` | `C major` | `false` |

確認できたこと。

```text
same function annotation candidate
  + same key context
  + different Γ_target_candidate_generation_fixture
  ↓
different generated target candidate sets
```

したがって、target候補集合はfunction annotation candidateの属性ではない。

## ■ 7. 暫定結論

47では、同じfunction annotation candidateと同じkey contextでも、target候補生成規則を変えると生成されるtarget候補集合が変わることを確認した。

```text
dominant_candidate + C major + Γ_A
  → {C major, A minor}

dominant_candidate + C major + Γ_B
  → {C major}
```

これは、target候補集合がfunction annotation candidateの内在属性ではなく、annotation、context、生成規則の関係として生じることを示す。

```text
generated target candidate set
  = C(function annotation candidate, key context; Γ_target_candidate_generation_fixture)
```

ただし、これはfixture内の限定表現であり、一般和声規則ではない。次の検証では、同じfunction annotation candidateと同じ生成規則でも、key contextを変えると候補集合が変わるかを見る。
