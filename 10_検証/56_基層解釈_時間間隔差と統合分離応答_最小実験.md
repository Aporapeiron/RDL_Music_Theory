# 検証記録：基層解釈・時間間隔差と統合/分離応答

*対象：A3「時間間隔と統合 / 分離」を、基層M_B確定ではなくM_B^base候補として観測する最小条件*  
*状態：DRAFT v0.1 / 50_既知基層解釈参照からのA3最小検証*  
*実装：`10_検証/base_temporal_integration_candidate.py`*

---

## ■ 0. 検証目的

`50_既知基層解釈参照/02_高優先M_B候補_硬い関係.md` では、A3として次を高優先候補に置いた。

```text
physical temporal separation
  ↓
human temporal integration
  ↓
integrated / separated perceptual response
```

ただし、既知研究で支持されることは、RDL基層M_Bとして確定することではない。

56では、既知参照点、`B_base`、`Γ_base`、観測された統合 / 分離応答差を分け、次だけを確認する。

```text
known A3 reference
  + B_base_temporal_integration_fixture
  + Γ_temporal_integration_comparison_fixture
  + perceptual response observations
  ↓
M_B^base candidate observed
  ↓
confirmed M_Bではない
```

ここでの `physical temporal separation` はdevice側で記述できる時間間隔差であり、`integrated / separated perceptual response` は人間側応答差である。両者を同一視しない。

---

## ■ 1. 固定する既知参照点

既知参照点を次に固定する。

```text
reference:
  A3 temporal-separation integration relation

claim scope:
  fixture_limited_reference_point
```

これは時間統合の完成モデルではなく、RDL側の最小検証へ送る参照基準点である。

---

## ■ 2. 固定するB_base

今回のBは、二つの短音イベント間隔と統合 / 分離型の知覚応答を比較するためのfixture境界である。

```text
B_base_temporal_integration_fixture:
  stimulus_form = two_click_event_fixture
  event_duration = 5 ms
  observation_window = 250 ms
  response_axis = integrated_or_separated_perceptual_response
  measurement_form = abstract_temporal_response_label
```

実測gap thresholdや個人別時間分解能そのものは扱わない。統合 / 分離応答差ラベルを用いた最小構造検査である。

---

## ■ 3. 固定するΓ_base

```text
Γ_temporal_integration_comparison_fixture:
  physical temporal separation
  と
  perceptual integration state
  の対応を比較する
```

このΓは、一般的な時間統合モデルでも、rhythm category生成規則でも、meter生成規則でもない。

---

## ■ 4. 最小入力

二つの時間イベントペアと、fixture知覚応答観測を用意する。

```text
input A:
  first event = 0 ms
  second event = 8 ms
  physical temporal separation = 8 ms
  perceptual integration state = integrated_response

input B:
  first event = 0 ms
  second event = 80 ms
  physical temporal separation = 80 ms
  perceptual integration state = separated_response
```

ここで確認するのは、時間間隔差と統合 / 分離応答差が同じfixture内で対応して観測されることだけである。

---

## ■ 5. 観測結果

| first event | second event | physical temporal separation | perceptual integration state | B_base | Γ_base |
|---:|---:|---:|---|---|---|
| 0 ms | 8 ms | 8 ms | `integrated_response` | same | same |
| 0 ms | 80 ms | 80 ms | `separated_response` | same | same |

確認できたこと。

```text
same B_base
same Γ_base
different physical temporal separation
↓
different perceptual integration state
↓
M_B^base candidate observed
```

ただし、これはconfirmed M_Bではない。

```text
M_B^base candidate observed
  ≠ confirmed M_B^base
```

また、時間間隔差からrhythm categoryやmeter categoryは生成しない。

```text
physical temporal separation
  ≠ generated rhythm category
  ≠ generated meter category
```

## ■ 7. まだ言えないこと

今回の検証から、次は言えない。

```text
時間統合がRDL基層M_Bとして確定したこと
単一の時間統合閾値が人間一般の固定境界であること
rhythm categoryが生成されたこと
beat / meterが説明されたこと
音楽的同時性が定義されたこと
device側時間間隔差とhuman側統合 / 分離応答が同一であること
F_deviceとF_humanが同一であること
```

また、今回のperceptual integration stateはfixtureラベルであり、実測psychophysical dataではない。

## ■ 8. 暫定結論

56では、既知参照点A3を、RDL側で次のように読めることを最小確認した。

```text
known A3 reference
  + B_base_temporal_integration_fixture
  + Γ_temporal_integration_comparison_fixture
  + perceptual response observations
  → M_B^base candidate observed
```

これは基層M_Bの確定ではなく、独立検査へ送れる候補関係の観測である。

54〜56を並べると、基層候補の入口が次のように分かれる。

```text
54:
physical frequency difference
  → frequency-selective response difference candidate

55:
physical Δf
  → behavioral discriminability difference candidate

56:
physical temporal separation
  → integrated / separated response difference candidate
```

次に進むなら、A1〜A3を一度構造抽出し、基層候補検証の共通型を圧縮する。
