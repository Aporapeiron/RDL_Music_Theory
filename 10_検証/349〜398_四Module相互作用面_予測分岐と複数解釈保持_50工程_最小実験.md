## ■ 0. 検証目的

299〜348では、四Module相互作用面を50工程で通し、相互作用しても統合Moduleへ潰さないことを確認した。

349〜398では、その相互作用面が実際に予測を一意化するのではなく、複数解釈を保持できるかを見る。

```text
same evidence bundle
  ↓
voice leading result = E4-C5
  ↓
next context candidates
  ↓
C major continuation
+ A minor reinterpretation
  ↓
external policyまで複数解釈を保持
```

ここでの主語は、抽象的な推論一般ではなく音楽的解釈である。したがって、分岐は失敗ではなく、音楽的情報として扱う。

## ■ 3. 分岐した予測候補

同じ具体声部進行結果を使う。

```text
selected target = C major
concrete target pair = E4-C5
motion = contrary motion
```

そこから、next context候補として少なくとも二つの読みが残る。

```text
C major continuation frame:
  harmonic_reading = tonic_continuation
  prediction = continue_C_major_context

A minor reinterpretation frame:
  harmonic_reading = relative_minor_reinterpretation
  prediction = reinterpret_as_A_minor_context
```

この二つは、同じE4-C5を材料にしているが、未来文脈の読みが違う。

## ■ 4. policy境界

policyなしでは、予測は一意化しない。

```text
without policy:
  status = underdetermined
  selected_prediction = None
  retained_alternatives = 2
```

外部policyを与えた場合だけ、選択が起こる。

```text
with prefer_continuation_fixture:
  selected_prediction = C major continuation frame
  retained_alternatives = A minor reinterpretation frame
```

ただし、選択は代替解釈の消去ではない。

## ■ 6. 暫定結論

349〜398では、四Module相互作用面が、単に接続可能であるだけでなく、予測分岐を保持できることを確認した。

```text
同じ根拠束から
複数の音楽的未来が読める

policyがあれば選べる
しかし選択しても代替解釈は消えない
```

これにより、相互作用網は「一意予測器」ではなく、音楽的解釈空間を保持する境界列として扱える。
