# 検証記録：波形関係からM_B候補が立ち上がる条件

*対象：音名・コード・調性より下位の波形関係*
*状態：DRAFT v0.1 / RDL音楽_Coreへの追加前の検証*
*実装：`10_検証/two_sine_wave_relations.py`*

---

## ■ 0. 検証目的

前段では、

```text
B + M_B + Γ → C(B, M_B;Γ)
```

として、C majorの候補空間が音名・音階・三和音の生成規則に依存することを確認した。

今回はさらに一段下げ、音名やコードを入力しない。

```text
F(t) = sin(2π f1 t) + sin(2π f2 t)
```

という2本の正弦波を最小入力とし、周波数比・共通周期・反復性を関係として抽出する。

ここで調べるのは、単一の「安定性」ではない。

```text
F_wave
↓ B_wave_observation
複数の関係を抽出
├─ 周波数比
├─ 差周波数
├─ 共通周期・短周期再帰
└─ 実サンプル上の再帰誤差
```

それぞれについて、何が保存されているかを分けて記録する。

```text
ratio_preserved
short_recurrence_candidate
recurrence_error
```

ここで調べるのは、

```text
何を観測境界Bにすると
どの関係が抽出され
どこからM_B候補と仮置きできるか
```

である。

協和、不協和、音高、コード、調性は、この実験では定義しない。

---

## ■ 1. 入力を波形へ下げる

入力は音名集合ではなく、観測窓内のサンプル列とする。

```text
F(t) = sin(2π f1 t) + sin(2π f2 t)
```

最初の実験では、`f1`と`f2`を既知の観測成分として与える。
したがって、これは未知波形から周波数成分を推定するスペクトル解析ではない。
実サンプル列`F(t)`を生成し、その列から候補周期における再帰誤差を確認するための、波形関係の最初の足場である。

```text
f1 = 100 Hz
f2 = 200 Hz / 201 Hz / 150 Hz / √2 × 100 Hz
```

`100 Hz`という数値自体を音名や調律へ変換しない。
ここで保持するのは、成分間の関係である。

---

## ■ 2. B：観測境界

この実験の`B`は、次の観測条件をまとめたものとする。

```text
B_wave_observation:
  duration_s
  sample_rate_hz
```

それぞれの役割は異なる。

| 境界要素 | 役割 |
|---|---|
| `duration_s` | どれだけ長く波形を見るか |
| `sample_rate_hz` | 時間をどの細かさで観測するか |

周波数比の近似方法や候補化の閾値は、観測境界`B`とは分け、関係抽出規則`Γ_ratio_period`として置く。

```text
Γ_ratio_period:
  max_denominator
  ratio_tolerance
  min_repetitions
```

したがって、ここでの「単純な比」や「短い共通周期」は、波そのものに絶対的に付属するのでも、観測境界だけから決まるのでもない。

```text
F_wave + B_wave_observation + Γ_ratio_period
↓
抽出された関係候補
```

---

## ■ 3. Γ：関係抽出規則

`Γ_ratio_period`に従い、周波数比を最大分母`q`を持つ有理近似として調べる。

```text
r = f2 / f1
r ≈ p / q
```

このとき、近似関係から共通周期候補を、

```text
T_common_candidate = q / f1
```

と置く。

抽出する関係は次の通りである。

```text
frequency_ratio       = f2 / f1
rational_relation     = p : q
ratio_error            = |r - p/q|
difference_frequency   = |f2 - f1|
common_period_candidate_s = q / f1
observed_repetitions       = duration / common_period_candidate_s
phase_drift            = 近似共通周期後の位相ずれ
recurrence_error       = 実サンプル列の正規化再帰誤差
```

ここで、差周波数は関係の一つとして保持するが、緊張や不協和、
聴覚上の「うなり」とは呼ばない。うなりとして知覚されるかどうかは、
後段の聴覚・知覚境界へ残す。

---

## ■ 4. 保存関係の分離とM_B候補の仮置き

この実験では、`M_B`を一つの安定性フラグへ潰さない。
少なくとも次の二つを別の関係軸として記録する。

| 軸 | この実験での意味 |
|---|---|
| `ratio_preserved` | 固定周波数の既知成分モデル上で、`f2 / f1`が時間窓をまたいで保存される |
| `short_recurrence_candidate` | `Γ_ratio_period`の近似比と`B`内の反復回数によって、有限時間内の短い再帰を候補化できる |

前者は、後者の成立を必要としない。

```text
100 : 200
  ratio_preserved = true
  short_recurrence_candidate = true

100 : 201
  ratio_preserved = true
  short_recurrence_candidate = false  # 初期Γ

100 : 100√2
  ratio_preserved = true
  short_recurrence_candidate = false
```

`short`は絶対的な時間の短さではなく、現在の`B`と`Γ_ratio_period`に対して、
観測窓内で少なくとも`min_repetitions`回の再帰が立ち上がることを指す。

```text
ratio_error <= ratio_tolerance
observed_repetitions >= min_repetitions
```

つまり、

```text
B + 波形成分 + Γ_ratio_period
↓
観測境界内で短く再帰する関係
↓
short_recurrence_candidate
```

と読む。これは`M_B`候補群のうち、周期・再帰に関する一軸である。

一方、`ratio_preserved`は、既知成分モデルから直接得ている。
この段階では実サンプル列から周波数比を推定していないため、
「波形から比を発見した」という意味ではない。

この判定は、波が「本質的に安定している」と宣言するものではない。
別の観測時間、許容誤差、最大分母、聴覚的境界を選べば、同じ波形から別の候補が立ち上がりうる。

---

## ■ 5. 最小ケース

初期境界を次のように置く。

```text
duration_s       = 4.0
sample_rate_hz   = 10000
```

関係抽出規則を次のように置く。

```text
max_denominator  = 16
ratio_tolerance  = 1e-6
min_repetitions  = 3
```

### 5.1 `100 Hz + 200 Hz`

```text
f2 / f1 = 2 / 1
T_common_candidate = 1 / 100 s
```

短い共通周期が観測窓内で多数反復する。
正規化再帰誤差もほぼ0になるため、現在の境界内では、

```text
short_recurrence_candidate
```

と記録できる。

ただし、これは「オクターブ」とはまだ呼ばない。
オクターブは後段の音高・知覚・音楽語彙による圧縮ラベルである。

### 5.2 `100 Hz + 150 Hz`

```text
f2 / f1 = 3 / 2
T_common_candidate = 2 / 100 s
```

これも短い共通周期を持つ関係候補になる。
`2:1`と`3:2`を、音楽的な協和順位に変換することは、この実験の範囲外である。

### 5.3 `100 Hz + 201 Hz`

初期の`Γ_ratio_period`では、`201/100`という複雑な比を候補化しない。
`max_denominator = 16`では、短い分母の関係として十分に近いとは判定されない。

初期条件では、`ratio_preserved`は成立するが、
`short_recurrence_candidate`は成立しない。

しかし、波形に差周波数がないという意味ではない。
`difference_frequency = 101 Hz`という関係は別に観測される。
ただし、`Γ_ratio_period`の`max_denominator`を128へ広げれば`201:100`が候補化される。

したがって、ここでの非候補は、

```text
no_short_relation_under_boundary
```

であり、波形に関係が存在しないことや、前段の`no_candidate`と同じ意味ではない。

### 5.4 `100 Hz + √2 × 100 Hz`

初期境界では、短い分母の有理関係としては候補化されない。
ただし、固定周波数成分モデルでは比自体は保存されるため、

```text
ratio_preserved = true
short_recurrence_candidate = false
```

となる。
ただし、`Γ_ratio_period`の最大分母や許容誤差を広げれば、有限観測の中で近似関係が立ち上がる可能性は残る。

これは、有限の`B`と`Γ`が連続的な波形関係から、短周期再帰だけを別の候補として切り出す例である。
近似関係が得られた場合も、直ちに恒常的な`M_B`とせず、境界依存の候補として扱う。

---

## ■ 6. 判定系と実波形検証系の分離

現在の実装には、二本の経路がある。

### 6.1 既知成分モデルによる関係候補

```text
(f1, f2)
↓ Γ_ratio_period
周波数比・有理近似・共通周期
↓
ratio_preserved
short_recurrence_candidate
```

`short_recurrence_candidate`の判定本体は、現状では
`ratio_error`と`observed_repetitions`である。

### 6.2 実サンプル列による補助観測

```text
F(t) = sin(2π f1 t) + sin(2π f2 t)
↓ B_wave_observation
実サンプル列
↓ 候補周期で比較
recurrence_error
```

`recurrence_error`は、既知成分モデルの判定を置き換えない。
現在は、モデルから得た候補周期が実サンプル列にも現れるかを確認する補助観測である。
将来、未知波形から成分を推定する段階へ進むと、ここから判定系へ接続しうる。

また、`B`の要素の作用先も同じではない。

| `B`の要素 | 現在の主な作用先 |
|---|---|
| `duration_s` | `observed_repetitions`、したがって短周期再帰候補の判定 |
| `sample_rate_hz` | サンプル列の生成と`recurrence_error`の測定精度 |

したがって、`B`の全要素が同じ`Γ`や同じ候補判定へ作用するとは置かない。

---

## ■ 7. 波形から音名までの暫定階層

今回の実験から、少なくとも次の階層を仮置きできる。

```text
物理波形 F_wave
    ↓ B_wave_observation
観測された成分間関係
    ├─ 周波数比の保存
    ├─ 差周波数
    ├─ 反復・同期・共通周期
    └─ 実サンプル再帰誤差
    ↓
保存関係ごとのM_B候補群
    ↓ 聴覚・知覚境界
知覚上の音高・まとまり
    ↓
音名・音程・コード・調性の圧縮ラベル
```

この階層は、下位が上位を一意に決定するという意味ではない。
知覚、注意、履歴、マスキング、音量、文化的慣習などが別の`B`として作用しうる。

したがって、

```text
物理波 = 音楽
```

とは置かない。

---

## ■ 8. 今回確認できたこと

```text
音名・コード・調性を使わずに、2本の波から関係候補を抽出できる。
周波数比の保存と、短い共通周期・反復性は別の関係として記述できる。
差周波数と共通周期も別の関係として保持できる。
非周期的な比でも、比の保存関係は候補として残せる。
既知成分モデルによる判定と、実サンプル列による再帰誤差の検証を分けられる。
同じ波形でも、観測境界や関係抽出規則を変えるとM_B候補の有無が変わる。
M_B候補は、波形そのものの絶対的性質ではなく、B内での暫定状態である。
```

---

## ■ 9. 今回まだ確定していないこと

この実験は、次の問題をまだ扱わない。

```text
未知波形からf1・f2をどう推定するか
部分音を含む実音のスペクトル構造をどう扱うか
聴覚上の音高がどの関係から生じるか
協和・不協和をどの境界で記述するか
注意・履歴・マスキングが関係抽出をどう変えるか
複数成分からM_B候補をどう統合するか
```

特に、`ratio_preserved`と`short_recurrence_candidate`はいずれも実験用の観測軸であり、
RDL音楽_Coreの新しい基本原理ではない。
波形関係の再現性と破断点を別の境界で検証した後、必要なら音響関係Moduleへ分岐する。

---

## ■ 10. 暫定構造

```text
F_wave
  ↓ B_wave_observation
観測成分 f1, f2
  ↓ Γ_ratio_period
関係候補群
  ├─ ratio_preserved
  ├─ short_recurrence_candidate
  └─ difference_frequency
  ↓ 実サンプルで補助観測
recurrence_error
  ↓
保存関係ごとのM_B候補群
  ↓
知覚・音楽理論Module
```

現段階では、従来の

```text
B + M_B + Γ → C(B, M_B;Γ)
```

を破棄するのではなく、候補生成の前段に、

```text
F_wave → B → 複数の関係抽出 → 保存関係ごとのM_B候補群
```

を追加する形で保持する。
