# 検証記録：基層解釈・周波数差と弁別可能性

*対象：A2「周波数差と弁別可能性」を、基層M_B確定ではなくM_B^base候補として観測する最小条件*  
*状態：DRAFT v0.1 / 50_既知基層解釈参照からのA2最小検証*  
*実装：`10_検証/base_frequency_discriminability_candidate.py`*

---

## ■ 0. 検証目的

`50_既知基層解釈参照/02_高優先M_B候補_硬い関係.md` では、A2として次を高優先候補に置いた。

```text
physical Δf
  ↓ B_frequency_discrimination
Γ_same_different
  ↓
behavioral discriminability
```

ただし、既知研究で支持されることは、RDL基層M_Bとして確定することではない。

55では、既知参照点、`B_base`、`Γ_base`、観測された弁別応答差を分け、次だけを確認する。

```text
known A2 reference
  + B_base_frequency_discrimination_fixture
  + Γ_frequency_discriminability_comparison_fixture
  + behavioral response observations
  ↓
M_B^base candidate observed
  ↓
confirmed M_Bではない
```

ここでの `physical Δf` はdevice側で記述できる周波数差であり、`behavioral discriminability` は人間側応答差である。両者を同一視しない。

---

## ■ 1. 固定する既知参照点

既知参照点を次に固定する。

```text
reference:
  A2 frequency-difference discriminability relation

claim scope:
  fixture_limited_reference_point
```

これは周波数弁別の完成モデルではなく、RDL側の最小検証へ送る参照基準点である。

---

## ■ 2. 固定するB_base

今回のBは、周波数差とsame / different型の弁別応答を比較するためのfixture境界である。

```text
B_base_frequency_discrimination_fixture:
  base_frequency = 1000 Hz
  stimulus_form = pure_tone_pair_fixture
  stimulus_duration = 200 ms
  response_axis = same_different_behavioral_response
  measurement_form = abstract_psychometric_response_label
```

実測psychometric curveや個人別閾値そのものは扱わない。弁別応答差ラベルを用いた最小構造検査である。

---

## ■ 3. 固定するΓ_base

```text
Γ_frequency_discriminability_comparison_fixture:
  physical Δf
  と
  behavioral discriminability
  の対応を比較する
```

このΓは、一般的な周波数弁別モデルでも、pitch category生成規則でも、semitone知覚規則でもない。

---

## ■ 4. 最小入力

二つの周波数ペアと、fixture弁別応答観測を用意する。

```text
input A:
  base frequency = 1000 Hz
  comparison frequency = 1002 Hz
  physical Δf = 2 Hz
  behavioral discriminability = low_discriminability

input B:
  base frequency = 1000 Hz
  comparison frequency = 1040 Hz
  physical Δf = 40 Hz
  behavioral discriminability = high_discriminability
```

ここで確認するのは、周波数差と弁別可能性差が同じfixture内で対応して観測されることだけである。

---

## ■ 5. 観測結果

| base frequency | comparison frequency | physical Δf | behavioral discriminability | B_base | Γ_base |
|---:|---:|---:|---|---|---|
| 1000 Hz | 1002 Hz | 2 Hz | `low_discriminability` | same | same |
| 1000 Hz | 1040 Hz | 40 Hz | `high_discriminability` | same | same |

確認できたこと。

```text
same B_base
same Γ_base
different physical Δf
↓
different behavioral discriminability
↓
M_B^base candidate observed
```

ただし、これはconfirmed M_Bではない。

```text
M_B^base candidate observed
  ≠ confirmed M_B^base
```

また、周波数差からpitch categoryやsemitone categoryは生成しない。

```text
physical Δf
  ≠ generated pitch category
  ≠ generated semitone category
```

## ■ 7. まだ言えないこと

今回の検証から、次は言えない。

```text
周波数弁別がRDL基層M_Bとして確定したこと
単一のdifference limenが人間一般の固定境界であること
pitch categoryが生成されたこと
semitone知覚が説明されたこと
音名・音程・調性が説明されたこと
device側周波数差とhuman側弁別応答が同一であること

```

また、今回のbehavioral discriminabilityはfixtureラベルであり、実測psychometric dataではない。

## ■ 8. 暫定結論

55では、既知参照点A2を、RDL側で次のように読めることを最小確認した。

```text
known A2 reference
  + B_base_frequency_discrimination_fixture
  + Γ_frequency_discriminability_comparison_fixture
  + behavioral response observations
  → M_B^base candidate observed
```

これは基層M_Bの確定ではなく、独立検査へ送れる候補関係の観測である。

54と55を並べると、基層候補の入口が次のように分かれる。

```text
54:
physical frequency difference
  → frequency-selective response difference candidate

55:
physical Δf
  → behavioral discriminability difference candidate
```

次に進むなら、A3として `physical temporal separation → integrated / separated perceptual response` を同じ形式で検査する。
