# 検証記録：短時間の関係破断と観測分解能

*対象：音名・コード・調性より下位の波形関係*  
*状態：DRAFT v0.1 / RDL音楽_Coreへの追加前の検証*  
*実装：`10_検証/short_ratio_break_resolution.py`*

---

## ■ 0. 検証目的

07では、時間変化する周波数の絶対値と比を別々に観測した。今回は、比が短時間だけ破れるケースを作り、観測分解能によってその破断が検出されたり見落とされたりするかを確認する。

今回分けるのは、次の三つである。

```text
既知モデルに、関係の破断が組み込まれている
観測時間窓Bの内部に、破断区間が存在する
観測点上で、関係の破れを検出できる
```

したがって、粗い観測で`ratio_preserved`に見えても、それは連続時間で比が保存されたことを意味しない。

```text
モデルに組み込まれた破断
≠
Bの観測時間窓との交差
≠
Bの観測点で検出された破断
```

---

## ■ 1. 破断を含む既知成分モデル

第1成分は固定する。

```text
f1(t) = 100 Hz
```

第2成分との比は、通常は`1.5`だが、0.5 msだけ`1.6`へ移動する。

```text
通常：       f2(t) / f1(t) = 1.5
破断区間：   f2(t) / f1(t) = 1.6
```

破断区間は次の半開区間とする。

```text
1.23425 s ≤ t < 1.23475 s
```

これは、

```text
break_duration = 0.0005 s
```

に相当する。破断区間の前後では比を`1.5`へ戻す。

この実験も未知波形から`f1`・`f2`を推定するものではない。瞬時周波数軌道を既知モデルとして与え、Bのサンプル時点で比を観測する。

---

## ■ 2. 波形生成

07と同じく、周波数を直接`sin(2π f(t)t)`へ代入せず、位相を積分する。

```text
phase_i(t) = 2π ∫_0^t f_i(τ)dτ
F(t) = sin(phase_1(t)) + sin(phase_2(t))
```

第2成分の位相は、通常比による積分に、破断区間に入った時間の補正を加えて求める。これにより、瞬時周波数の短時間変化を波形列にも反映する。

ただし、今回の破断検出は波形列から比を推定して行わない。

```text
既知の瞬時周波数モデル → Bの時点で比を観測
生成されたF(t)        → 波形の補助記録
```

この二本を混同しない。

---

## ■ 3. 観測境界Bと判定規則Γ_point_ratio

観測時間窓は`[0, duration_s)`の2秒とする。サンプル時刻は、観測格子の開始位相を含む等間隔の点である。今回の開始位相は0秒だが、09では同じsample_rateのままこの値をずらす。

```text
B:
  duration_s      = 2.0
  sample_rate_hz  = 10000 または 1000
```

サンプル時刻は、実装上、終点を含まない。

```text
t_n = sampling_phase_s + n / sample_rate_hz
```

判定規則は、観測された比の初期値からの最大偏差を見る。

```text
r_n = f2(t_n) / f1(t_n)
r_0 = f2(t_0) / f1(t_0)
max_observed_ratio_deviation = max_n |r_n - r_0|
```

ここで、モデルに破断が組み込まれているか、破断区間が観測時間窓Bと交差するかは、観測点の結果とは別に記録する。

```text
model_ratio_break_present
break_intersects_observation_window
```

観測点から破断を検出できたかは、`Γ_point_ratio`による別の値として記録する。

```text
sampled_break_detected
observed_ratio_preserved
```

後者は、正確には「観測点では破断を検出しなかった」という意味である。

---

## ■ 4. 2つの観測境界

### 高分解能：10 kHz

サンプル間隔は、

```text
0.1 ms
```

である。破断区間には複数のサンプル時点が入る。

```text
model_ratio_break_present = true
break_intersects_observation_window = true
sampled_break_detected          = true
observed_ratio_preserved        = false
```

### 粗い分解能：1 kHz

サンプル間隔は、

```text
1 ms
```

である。今回のサンプル位相では、破断区間の内側にサンプル時点がない。

```text
model_ratio_break_present = true
break_intersects_observation_window = true
sampled_break_detected          = false
observed_ratio_preserved        = true
```

この`observed_ratio_preserved`は、連続時間での保存を意味しない。今回のBが拾った時点では、破断が観測されなかっただけである。

---

## ■ 5. 判定軸

| 軸 | 意味 |
|---|---|
| `model_ratio_break_present` | 既知モデルに短時間の比破断が組み込まれている |
| `break_intersects_observation_window` | 破断区間と観測時間窓Bが交差している |
| `sampled_break_detected` | Bのサンプル時点の少なくとも1点で比破断を検出した |
| `observed_ratio_preserved` | Bのサンプル時点を`Γ_point_ratio`で見たとき、初期比からの破れを検出しなかった |
| `sampled_break_count` | 破断区間に入ったサンプル時点の数 |
| `max_observed_ratio_deviation` | サンプル時点だけで測った比の最大偏差 |
| `waveform_peak` / `waveform_rms` | 生成された実サンプル列の補助記録 |

特に、次の二つは同じではない。

```text
model_ratio_break_present
≠
sampled_break_detected
```

---

## ■ 6. 期待される結果

| B | 破断区間内のサンプル | モデル上の破断 | 観測上の破断 | 観測上の比保存 |
|---|---:|---:|---:|---:|
| 10 kHz | 複数 | あり | 検出 | なし |
| 1 kHz | 0 | あり | 見落とし | ありに見える |

この結果が得られれば、同じ対象と同じ関係でも、Bの時間分解能によって`M_B候補`の記述が変わることになる。

```text
B細かい
↓
局所破断を観測

B粗い
↓
局所破断を未観測のまま、保存に見える
```

ここで、1 kHzのBが破断を検出しなかったことだけから、未観測部分の中身を「0.5 msの比破断」と確定してはいけない。0.5 msの破断は、細かいBまたは外部の既知モデルによって事後的に分かった内容であり、粗いBにとっては未回収領域`ξ`の一例である。

```text
粗いB
→ 破断を検出できない
→ そのBでは比保存というM_B候補が立つ
→ ただし未回収領域ξが残る

細かいB / 外部の既知モデル
→ 破断を発見する
→ 粗いBが回収できなかった内容の一部が事後的に判明する
```

`ξ`は実装が直接計算する量ではなく、観測結果と既知モデルの差を記述するための位置づけである。

## ■ 7. RDL上の位置づけ

07では、保存関係を複数の軸へ分けた。08では、その各軸の判定自体がBに依存することを確認する。

```text
対象の既知軌道
↓
B：観測時間・時間分解能・観測格子の開始位相
↓
W：比のサンプル列
↓
Γ_point_ratio：点サンプル比の破断検出規則
↓
検出された保存 / 破断
```

したがって、現段階の`M_B候補`は、単に対象が持つ固定的な性質ではない。

```text
対象 + B + Γ_point_ratio
↓
そのBとΓ_point_ratioで保存に見える関係
```

これは、

```text
関係が保存されている
```

という記述を、少なくとも、

```text
この観測境界Bで、関係の破れを検出しなかった
```

へ分解するための最小例である。

---

## ■ 8. 今回まだ確定していないこと

```text
未知波形から局所的な比破断を推定する方法
サンプル間の破断を補間・復元する方法
波形列の位相痕跡を使う別のΓによる再検出
観測格子の開始位相を変えた場合の検出確率
破断時間とsample_rate_hzの一般的な閾値
聴覚上の短時間破断の知覚可能性
```

特に、今回の1 kHzでの見落としは、あらゆる1 kHz観測が見落とすという意味ではない。破断区間とサンプル格子の位相関係に依存する、一つのBの実例である。

---

## ■ 9. 暫定結論

```text
既知モデルには、0.5 msの比破断が組み込まれている。
10 kHzでは、その破断を観測点から検出できる。
1 kHzでは、今回のBとΓ_point_ratioでは破断を見落とす。
粗いBでの「比保存」は、連続時間の比保存を保証しない。
```

したがって、08から得られる暫定的な記述は、

```text
M_B候補
=
BとΓ_point_ratioのもとで、破断を検出せず保存として扱える関係
```

である。

これは「関係が実際に破れていない」とは異なる。また、1 kHzで破断が観測不能だと一般化することもできない。どの破断が観測され、どの破断が未観測のまま残るかは、BだけでなくΓにも依存する。
