# 検証記録：音程分解・周波数比から12TET半音数までの最小接続検査

*対象：周波数関係から連続座標・12TET上の半音数へ至る変換*
*状態：DRAFT v0.2 / 音程分解Module候補*
*実装：`10_検証/interval_fifth_decomposition.py`*

---

## ■ 0. 検証目的

既知音楽理論を正解として採用するのではなく、長期的に蓄積された人間の音楽的記述を、下位の関係へ逆分解する。

今回の対象は、純正五度と12TET五度を比較しながら、音程名の手前で止める。

```text
対象
  f1, f2
    ↓ Γ_ratio
周波数比 r = f2 / f1
    ↓ Γ_cents
連続的な音程座標 Δc
    ↓ Γ_12TET_round
12TET上の7半音
```

今回の検証は、次の一点を確認する。

```text
物理的には異なる比
    ↓
同じ12TET上の半音数へ写る
```

ここでは、`7半音 → 完全五度`の接続を扱わない。音程名には音名・綴りによるgeneric intervalが必要であり、これは11で分離して検証する。

```text
12TET上の7半音
≠
一意に定まった音程名
```

また、既知理論のカテゴリー写像は、人間の基層知覚そのものではない。

```text
既知理論のカテゴリー写像
≠
人間のM_Bそのもの
```

## ■ 1. 層の切り分け

### 1.1 対象側

今回比較する数値は観測境界ではなく、対象側の値である。

```text
対象:
  f1 = 100 Hz
  f2 = 150 Hz

対象:
  f1 = 100 Hz
  f2 = 100 × 2^(7/12) Hz
```

ここから周波数比を抽出する。

```text
r = f2 / f1
```

### 1.2 B

今回の`B`は、何を既知として、何を比較対象にするかを指定する。

```text
B_interval:
  known_components = true
  component_count = 2
  stationary_frequency = true
  direction = f2 / f1
```

したがって、`f1_hz`と`f2_hz`は対象側にあり、Bそのものではない。

身体・装置・環境が事実上課す境界、時間窓、サンプル分解能、聴覚器官の制約は今回のBには含めず、別の検証へ送る。

### 1.3 物理関係と数学的座標化

純正五度と12TET五度は、次の異なる周波数比を持つ。

| 記述 | 周波数比 | セント値 |
|---|---:|---:|
| 純正五度の代表比 | `3/2 = 1.5` | 約 `701.955` cents |
| 12TETの7半音 | `2^(7/12) ≈ 1.498307` | `700` cents |

セントは、比を対数的な音程座標へ置くための数学的記述である。

```text
Δ_oct = log2(r)
Δ_cents = 1200 log2(r)
```

`Γ_cents`は物理現象そのものではなく、物理比を表現する座標化規則である。この実験だけから、これが聴覚器官の基層規則だとは結論しない。

### 1.4 learned側

12TETの半音数への写像を、既知の調律・記述体系による離散化として置く。

```text
n_12TET = round(12 log2(r))
residual_cents = 1200 log2(r) - 100 n_12TET
```

これは次の段階までを扱う。

```text
物理比
  ↓ Γ_cents
連続座標
  ↓ Γ_12TET_round
7半音という離散記述
```

音名・綴りを必要とする`P5`や`d6`への分岐は、別のlearned構造として11で検証する。

### 1.5 context側

次の内容は今回の範囲から除外する。

```text
V7からtonicへの解決
dominantとしての機能
調性内での期待
旋律・和声・物語上の意味
```

## ■ 2. Γの切り分け

```text
Γ_ratio          周波数比 r を計算する
Γ_cents          比をセント座標へ変換する
Γ_12TET_round    12TET上の最近傍半音へ丸める
```

`Γ_12TET_round`は、物理対象から自然に一意に出てくる法則ではない。既知の調律・音楽記述体系を適用するための規則である。

今回の実装では、音程名を返す`label_12tet()`を置かない。7半音から音程名へ進むには、音名・綴りを入力とする別の`Γ_spelling`が必要になるためである。

## ■ 3. 最小ケース

### 3.1 純正五度の代表比

```text
f1 = 100 Hz
f2 = 150 Hz
r  = 3/2
Δc = 約701.955 cents
```

12TETへの写像では、最近傍の7半音になる。

```text
12TET category = 7 semitones
residual       = 約+1.955 cents
```

### 3.2 12TETの7半音

```text
f1 = 100 Hz
f2 = 100 × 2^(7/12) Hz
r  = 約1.498307
Δc = 700 cents
```

こちらも7半音へ写るが、純正五度とは物理比が異なる。

### 3.3 何が保存され、何が圧縮されるか

| 層 | 純正五度と12TETの7半音の関係 |
|---|---|
| 対象側の周波数比 | 異なる `r` |
| 数学的座標 | 約1.955 cents異なる |
| 12TET記述 | ともに7半音 |
| 音程名 | 今回は未判定 |
| 和声機能 | 今回は未検査 |

ここで観測されるのは、物理差が消滅したことではない。

```text
物理差を残したまま、特定のΓによって同じ離散記述へ圧縮された
```

## ■ 4. 転置不変性の最小確認

同じ比を保ったまま絶対周波数を変える。

```text
100 Hz : 150 Hz = 200 Hz : 300 Hz = 3 : 2
```

このとき、次が保存される。

```text
r
Δc
n_12TET
residual_cents
```

これは、今回の音程記述が絶対周波数ではなく関係比を軸にしていることの最小確認である。ただし、人間が同じ音程として知覚することまでは、この計算から導けない。

## ■ 5. A・B・Cタグの仮置き

ここでのA・B・Cは、理論の階層そのものではなく、寄与の強さを調べるための診断タグである。

### A：物理関係の寄与が強い

```text
周波数比 r
比の保存
```

### 座標化：物理関係を記述する数学的規則

```text
セント座標
```

セントは物理関係を変えるものではないが、物理比を比較可能な連続座標へ置くための`Γ_cents`による記述である。

### B：learnedが離散化・カテゴリー化

```text
12TET最近傍7半音への写像
```

「完全五度」という名称は、音名・綴りを必要とするため、今回のBにはまだ含めない。11で、同じ7半音が`P5`と`d6`へ分岐する条件を調べる。

### C：文脈・文化・学習の寄与が強い

```text
dominantとしての機能
tonicへの解決期待
様式内での意味
```

## ■ 6. この実験から言えること

```text
1. 純正五度の代表比と12TETの7半音は、物理的に異なる周波数比を持つ。
2. セント座標では、両者に約1.955 centsの差がある。
3. Γ_12TET_roundを適用すると、両者は7半音へ写る。
4. 既知音楽理論には、物理関係を連続座標化し、さらに離散化する段階がある。
5. これは人間のM_Bそのものではなく、M_B^learnedの言語化・体系化された痕跡として扱う。
```

特に、次の二つを分ける。

```text
物理的に同じ
≠
同じ12TET記述カテゴリーへ写る
```

## ■ 7. まだ言えないこと

```text
人間が純正五度と12TETの7半音を必ず同じ音程として聴くこと
約1.955 centsが常に知覚上無視されること
「7半音」から音程名が一意に定まること
音程名の知覚境界
波形・音色・音域・音量によるカテゴリー境界の変化
文化や教育がカテゴリーへ与える影響
五度が協和として感じられる理由
dominantがtonicへ解決したがる理由
```

これらは、`B_base`・`Γ_base`・`M_B^learned`・`M_B^context`を分けた次の検査へ送る。

## ■ 8. 暫定結論

今回の接続は、次の形で閉じる。

```text
対象側の f1, f2
    ↓ Γ_ratio
周波数比 r
    ↓ Γ_cents
数学的な連続座標
    ↓ Γ_12TET_round
7半音という離散記述
```

ここで、純正五度の代表比と12TETの7半音は、物理関係としては異なる。しかし、既知の12TET記述規則では同じ7半音へ入る。

一方、次の接続は未回収である。

```text
7半音
    ↓ 音名・綴り
generic interval
    ↓ quality判定
P5 / d6
```

したがって、10の成果は「完全五度という名称を物理比から導いたこと」ではなく、物理比から12TET上の半音数へ至る中間層を切り出したことである。

次の11では、同じ7半音が、音名・綴りという別の`M_B^learned`によって異なる音程名へ分岐することを検査する。
