# 検証記録：用途別状態同一性

*対象：音程Moduleの`DynamicSearchState`*  
*状態：DRAFT v0.1 / state IDを変えない同一性判定の明示*

38の三観測断面に対応して、比較用の三判定を追加する。

```text
same_for_candidate_generation(source, resulting) = True
same_for_controller(source, resulting)           = False
same_for_history(source, resulting)              = True
```

これは`state_id`の置換ではない。呼び出し側が何を同一と見なすのかを、candidate generation・controller・historyの現在の利用関係ごとに明示する観測ヘルパーである。

三判定も排他的な型分類ではない。各判定は38のprojectionを比較するため、同じfieldが複数判定へ関与し得る。共通state、共通controller、state ID規則、状態クラス分割は導入しない。
