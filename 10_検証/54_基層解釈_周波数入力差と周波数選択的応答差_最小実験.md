# 検証記録：基層解釈・周波数入力差と周波数選択的応答差

*対象：A1「周波数入力と周波数選択的配置・応答」を、基層M_B確定ではなくM_B^base候補として観測する最小条件*  
*状態：DRAFT v0.1 / 50_既知基層解釈参照からの初回最小検証*  
*実装：`10_検証/base_frequency_selective_response_candidate.py`*

---

## ■ 0. 検証目的

`50_既知基層解釈参照/02_高優先M_B候補_硬い関係.md` では、A1として次を高優先候補に置いた。

```text
physical frequency difference
  ↓
human auditory system
  ↓
systematic frequency-selective response difference
```

ただし、既知研究で支持されることは、RDL基層M_Bとして確定することではない。

54では、既知参照点、`B_base`、`Γ_base`、観測された応答差を分け、次だけを確認する。

```text
known A1 reference
  + B_base_frequency_response_fixture
  + Γ_frequency_response_comparison_fixture
  + response observations
  ↓
M_B^base candidate observed
  ↓
confirmed M_Bではない
```

---

## ■ 1. 固定する既知参照点

既知参照点を次に固定する。

```text
reference:
  A1 frequency-selective response relation

claim scope:
  fixture_limited_reference_point
```

これは人間聴覚の完成モデルではなく、RDL側の最小検証へ送る参照基準点である。

---

## ■ 2. 固定するB_base

今回のBは、周波数入力と応答選択性を比較するためのfixture境界である。

```text
B_base_frequency_response_fixture:
  frequency_range = 100 Hz - 5000 Hz
  stimulus_form = pure_tone_fixture
  response_axis = frequency_selective_region
  measurement_form = abstract_response_label
```

実測データや神経計測値そのものは扱わない。応答差ラベルを用いた最小構造検査である。

---

## ■ 3. 固定するΓ_base

```text
Γ_frequency_response_comparison_fixture:
  physical frequency input difference
  と
  response selective region difference
  の対応を比較する
```

このΓは、tonotopyの一般モデルでも、pitch知覚規則でもない。

---

## ■ 4. 最小入力

二つの周波数入力と、fixture応答観測を用意する。

```text
input A:
  frequency = 500 Hz
  response selective region = low_frequency_response_region

input B:
  frequency = 2000 Hz
  response selective region = high_frequency_response_region
```

ここで確認するのは、周波数入力差と応答選択性差が同じfixture内で対応して観測されることだけである。

---

## ■ 5. 観測結果

| input frequency | response selective region | B_base | Γ_base |
|---:|---|---|---|
| 500 Hz | `low_frequency_response_region` | same | same |
| 2000 Hz | `high_frequency_response_region` | same | same |

確認できたこと。

```text
same B_base
same Γ_base
different physical frequency input
↓
different response selective region
↓
M_B^base candidate observed
```

ただし、これはconfirmed M_Bではない。

```text
M_B^base candidate observed
  ≠ confirmed M_B^base
```

---

## ■ 6. Module責務の確認

今回の接続は、次のように分かれる。

```text
50_既知基層解釈参照:
  A1を既知参照点として渡す

B_base:
  比較する周波数範囲・刺激形式・応答軸を限定する

Γ_base:
  入力周波数差と応答選択性差の対応を比較する

M_B^base候補:
  BとΓのもとで保存候補として観測される

Core:
  変更しない
```

---

## ■ 7. まだ言えないこと

今回の検証から、次は言えない。

```text
tonotopyがRDL基層M_Bとして確定したこと
pitch知覚が説明されたこと
音名・音程・調性が説明されたこと
個体間で同じ固定mapがあること
周波数入力差からlearned音楽ラベルが生成されること
F_deviceとF_humanが同一であること
```

また、今回のresponse selective regionはfixtureラベルであり、実測脳部位や実測データではない。

---

## ■ 8. 暫定結論

54では、既知参照点A1を、RDL側で次のように読めることを最小確認した。

```text
known A1 reference
  + B_base_frequency_response_fixture
  + Γ_frequency_response_comparison_fixture
  + response observations
  → M_B^base candidate observed
```

これは基層M_Bの確定ではなく、独立検査へ送れる候補関係の観測である。

次に進むなら、A2として `physical Δf → behavioral discriminability` を同じ形式で検査する。
