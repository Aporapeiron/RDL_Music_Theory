# 検証記録：音程分解・同一トライトーンと綴りによる解決方向

*対象：同一の音響的トライトーンが、綴りを含む代表的な声部進行の中で異なる方向へ表現される条件*
*状態：DRAFT v0.1 / 音程分解Module候補*
*実装：`10_検証/tritone_spelling_resolution.py`*

---

## ■ 0. 検証目的

11では、同じ12TET上の物理音高対が、綴り情報を比較関係として保持するBを通すと、`P5`と`d6`へ分岐することを確認した。

12では、同じ構造をトライトーンへ移す。

```text
同一の12TET上の音高対
        ↓ B_spelling + Γ_interval
A4 / d5
        ↓ learned側の代表的解決候補を外部入力
target
        ↓ Γ_motion
外へ開く / 内へ狭まる
```

最小ケースは次の二つである。

```text
F4  – B4  = A4
E♯4 – B4  = d5
```

12TETでは`F4`と`E♯4`は同じ音高なので、開始時点の音響的な音高対は同一である。違うのは下音の綴りと、それによって生成されるgeneric interval・qualityである。

ただし、この実験は「綴りが物理的に声部を動かす」ことを示すものではない。また、コードは`A4 / d5`から解決先を自動生成しない。綴りを含む学習済みの記述構造に由来する代表的解決候補を外部から与え、その候補に対する声部運動の記述を分離して検査する。

したがって、ここでは次の二つを分ける。

```text
綴り・音程ラベル
  → learned側の代表的解決候補

与えられたtarget
  → Γ_motionによる運動方向の記述
```

---

## ■ 1. 対象とBの分離

### 1.1 開始対象側

開始対象は、トライトーンを構成する二音である。解決後の二音は開始対象から生成せず、別途、代表的解決候補として与える。

```text
対象A:
  start = F4  – B4

対象B:
  start = E♯4 – B4
```

開始時点では両対象の物理音高対が同じである。

```text
F4  = E♯4
B4  = B4
```

### 1.2 解決候補側

`target`は、今回のコードへ外部から与える代表的候補である。`A4 / d5`から一意に選択・生成されるものとして扱わない。

```text
候補A:
  label  = A4
  target = E4  – C5

候補B:
  label  = d5
  target = F♯4 – A♯4
```

この候補対応そのものが、既知音楽理論をlearned側の遷移`M_B`として読む際の対象になる。今回の最小実験では、その対応を検証するのではなく、固定した候補として受け取る。

### 1.3 B

今回のBは、次の関係を比較可能なものとして保持する。

```text
B_tritone_spelling:
  tuning = 12TET
  known_spelling = true
  ascending = true
  ordered_two_voice_pair = true
```

`B`は、対象に含まれる音名・綴り情報と、二声部の上下関係を保持する。解決先そのものや、外向き・内向きという結果はBへ混ぜない。

一方、`M_B^learned`は、Bで分岐したラベルに接続される代表的解決候補を持ちうる。今回のコードでは、その候補を次のように外部入力する。

```text
M_B^learned:
  representative_resolution_candidate = externally supplied
```

## ■ 2. Γの切り分け

```text
Γ_chromatic  12TET上の半音距離を抽出する
Γ_generic    音名上の文字間隔からgeneric intervalを抽出する
Γ_quality    generic intervalの基準値と実半音距離の差から品質を判定する
Γ_resolution 外部から与えられた解決候補を開始対象へ接続する
Γ_motion     接続されたtargetに対する各声部の絶対半音移動量と方向を比較する
```

開始音だけを`Γ_chromatic`で見ると、両対象は同じである。

```text
F4  – B4  = 6 semitones
E♯4 – B4  = 6 semitones
```

`Γ_generic`と`Γ_quality`を加えると、同じ6半音が分岐する。

```text
F → B  = 四度  + 1半音 = A4／増四度
E → B  = 五度  - 1半音 = d5／減五度
```

さらに、外部から与えた代表的解決候補に対して`Γ_motion`を適用する。

```text
A4:
  F4 → E4  = -1半音
  B4 → C5  = +1半音
  下声と上声が反対方向へ移動するため、外へ開く

d5:
  E♯4 → F♯4 = +1半音
  B4  → A♯4 = -1半音
  下声と上声が反対方向へ移動するため、内へ狭まる
```

この「解決方向」は、開始ラベルから機械的に普遍的に導かれたものではない。今回選択した二つの代表的ターゲットを入力し、そのtargetから声部移動の結果を機械的に記述したものである。

## ■ 3. 最小ケースの比較

| 開始対象 | 開始音程 | 開始半音数 | 外部入力した代表的解決候補 | 下声の移動 | 上声の移動 | 記述された方向 |
|---|---|---:|---|---:|---:|---|
| `F4 → B4` | A4／増四度 | 6 | `E4 → C5` | -1 | +1 | 外へ開く |
| `E♯4 → B4` | d5／減五度 | 6 | `F♯4 → A♯4` | +1 | -1 | 内へ狭まる |

開始時点で保存されるものは次である。

```text
F4とE♯4の絶対音高
B4の絶対音高
周波数比
cents
12TET上の6半音
```

綴りと選択した解決構造によって変わるものは次である。

```text
generic interval
音程品質
音程ラベル
解決ターゲット
各声部の移動方向
音程幅の変化
```

## ■ 4. A・B・Cタグの仮置き

### A：12TET物理モデル上の音高関係

```text
12TET規則から得た開始音高対
12TET上で同一の音高対
12TET規則から生成される同一の比
```

ここでのAは実波形や実測Hzそのものではない。`SpelledNote`を12TET規則で絶対半音位置へ写し、その差から音高関係と比を生成するモデル上の層である。

### 座標化：関係を比較可能にする記述規則

```text
cents
12TET上の半音数
```

### B：learned側の離散化・カテゴリー化

```text
音名・綴り情報を比較関係として保持するB
generic interval
A4 / d5という音程品質とラベル
代表的な解決ターゲットの対応候補
```

`A4 / d5`からどの解決先を候補として接続するかは、既知音楽理論が蓄積した遷移`M_B`の検査対象になりうる。ただし今回の検証では、その候補を外部から固定入力している。`A4 / d5`からtargetを自動生成する規則や、候補を一意に選ぶ規則は実装していない。

### C：文脈・機能の寄与が強い

```text
調性内での機能
和声進行全体
ジャンル・様式・教育による期待
実演上の発音・配置・履歴
```

今回の実験は、Cの機能判断を扱わない。

## ■ 5. この実験から言えること

```text
1. F4–B4とE♯4–B4は、12TET上の同一音高対である。
2. 両者は同じ6半音・同じ周波数比を持つ。
3. 綴りを保持すると、同じ6半音はA4とd5へ分岐する。
4. 外部から与えた代表的解決候補では、A4側は外へ開き、d5側は内へ狭まる。
5. targetが与えられた後の`target → motion`は機械的に記述できる。
6. 一方、`A4 / d5 → target候補`の対応は、learned側に保持されうる遷移`M_B`として別に扱う必要がある。
```

圧縮すると、次の形である。

```text
同一の音響的トライトーン
  ↓ Γ_chromatic
6半音
  ↓ B_spelling + Γ_generic + Γ_quality
A4 / d5
  ↓ learned側の代表的解決候補を外部入力
target
  ↓ Γ_motion
外へ開く / 内へ狭まる
```

11からの重要な接続は、単に「同じ音が別名になる」ことではない。綴りを比較関係として保持するBが、後続の候補構造を接続・分岐させる入口になりうる。今回のコードはその候補選択を行わず、候補が与えられた後の運動を観測している。

## ■ 6. まだ言えないこと

```text
人間がA4とd5を必ず異なるものとして知覚すること
綴り情報が実際の知覚より先に解決先を決めること
A4は常に外へ、d5は常に内へ解決すること
解決方向が音程ラベルだけから一意に決まること
トライトーンの解決感をHと直接同一視できること
文化・教育・ジャンルを越えた普遍的な声部進行であること
```

今回確認できたのは、同一の音響関係に、綴りから分岐した音程ラベルと、外部から固定した代表的ターゲットを接続した場合の記述分岐である。`target → motion`は機械的に検査できるが、`A4 / d5 → target候補`の対応がどのように形成・選択されるか、基層知覚が区別するか、現在文脈でどう機能化されるかは未検証のまま残る。

---

## ■ 7. 暫定結論

同じ12TET上の音高対でも、音名・綴りを保持することで`A4`と`d5`という別のlearned構造へ分岐する。さらに、learned側の代表的解決候補を外部から接続すると、二声部の運動は外向きと内向きへ分かれる。

```text
同じ音響関係
≠ 同じ綴り関係
≠ 同じ解決構造
```

ただし、ここで確認された因果は「綴りが単独で物理運動を生む」というものではない。

```text
同じ音響関係
＋ 綴りを保持するB
＋ 外部から与えた代表的解決ターゲット
↓
異なる声部運動の記述
```

ここで、`A4 / d5 → target候補`は既知音楽理論が蓄積した遷移`M_B`として、`target → motion`は関係抽出として分けて保持する。このため、12は音程分解の最小接続検査として閉じ、機能和声Moduleや一般的な知覚モデルへは拡張しない。
