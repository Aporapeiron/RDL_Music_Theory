# 検証記録：基層解釈・human-side response differenceとlearned category候補のbridge境界

*対象：`ξ_base_to_learned_bridge` を、human-side response differenceからlearned音楽カテゴリーを直生成せずに検査する最小条件*  
*状態：DRAFT v0.1 / 54〜56基層候補構造抽出後のbridge最小検証*  
*実装：`10_検証/base_to_learned_bridge_candidate.py`*

---

## ■ 0. 検証目的

`20_構造抽出/基層候補_A1〜A3_54〜56構造抽出版.md` では、54〜56の後に残る未解決ξとして次を置いた。

```text
ξ_base_to_learned_bridge:
  human-side response differenceからlearned音楽構造へ接続する条件

ξ_category_generation_boundary:
  pitch / interval / rhythm / meterなどの音楽カテゴリー生成境界
```

57では、この境界を閉じない。

human-side response differenceからlearned categoryを直接生成せず、外部から与えたlearned category候補集合と、fixture用の`Γ_bridge`を接続した場合だけ、bridge候補が観測できることを確認する。

```text
human-side response difference
  + external learned category candidates
  + Γ_base_to_learned_bridge_fixture
  ↓
bridge candidate observed
  ↓
selected musical interpretationは未生成
```

---

## ■ 1. 固定するhuman-side response difference

54〜56のうち、今回は55のA2系をbridge材料として使う。

```text
human-side response difference:
  label = A2 behavioral discriminability difference
  source_base_candidate = frequency_difference_to_behavioral_discriminability_candidate
  response_axis = behavioral_discriminability
  lower_response = low_discriminability
  higher_response = high_discriminability
  generated_learned_category = None
```

これは人間側の弁別応答差であり、pitch category、semitone category、音程認識そのものではない。

---

## ■ 2. 外部から与えるlearned category候補集合

learned側の候補を、response differenceから生成しない。外部fixtureとして次を与える。

```text
external learned category candidates:
  same_pitch_relation_label_candidate
  different_pitch_relation_label_candidate
```

これらは候補であり、確定カテゴリーでも選択済み音楽解釈でもない。

```text
external learned category candidate
  ≠ generated learned category
  ≠ selected musical interpretation
```

---

## ■ 3. 固定するΓ_bridge

```text
Γ_base_to_learned_bridge_fixture:
  human-side response difference
  と
  external learned category candidate
  のcompatibilityを読む
```

このΓは、一般的なcategory generation ruleではない。周波数弁別から半音知覚や音程認識を生成する規則でもない。

今回のfixtureでは、`A2 behavioral discriminability difference` と `different_pitch_relation_label_candidate` の間にだけ、bridge候補を置く。

---

## ■ 4. 最小ケース

### 4.1 Γ_bridgeなし

```text
human-side response difference
+ external learned category candidates
+ Γ_bridgeなし
↓
underdetermined_without_bridge_gamma
```

候補集合が外部から与えられていても、bridge Γがなければ接続は未決定である。

### 4.2 Γ_bridgeあり

```text
human-side response difference
+ external learned category candidates
+ Γ_base_to_learned_bridge_fixture
↓
bridge candidate observed
```

ただし、ここで得られるのはbridge候補であり、learned categoryの確定でも、選択済み音楽解釈でもない。

```text
bridge candidate observed
  ≠ confirmed learned category
  ≠ selected musical interpretation
```

---

## ■ 5. 観測結果

| input | external learned candidates | Γ_bridge | status | selected musical interpretation |
|---|---|---|---|---|
| `A2 behavioral discriminability difference` | same / different pitch-relation label candidates | none | `underdetermined_without_bridge_gamma` | `None` |
| `A2 behavioral discriminability difference` | same / different pitch-relation label candidates | fixture | `bridge_candidate_observed_not_selected` | `None` |

確認できたこと。

```text
same human-side response difference
same external learned category candidates
different Γ_bridge
↓
underdetermined / bridge candidate observed が分岐する
```

また、bridge候補が観測されても、learned categoryは生成されない。

```text
human-side response difference
  ≠ generated learned category

external learned category candidates
  ≠ generated by response difference

bridge candidate observed
  ≠ selected musical interpretation
```

---

## ■ 6. Module責務の確認

今回の接続は、次のように分かれる。

```text
基層候補側:
  human-side response differenceを渡す

learned側:
  learned category候補集合を外部入力として渡す

Γ_bridge:
  response differenceと候補のcompatibilityを読む

bridge候補:
  B / Γ / 候補集合のもとで観測される

中核音楽理論:
  今回は未接続
```

したがって、基層候補はlearned音楽カテゴリーを自動生成していない。

---

## ■ 7. まだ言えないこと

今回の検証から、次は言えない。

```text
周波数弁別からpitch categoryが生成されたこと
周波数弁別からsemitone categoryが生成されたこと
周波数弁別から音程認識が生成されたこと
bridge候補が正しいlearned categoryであること
bridge候補がselected musical interpretationであること
human-side response differenceがlearned音楽カテゴリーと同一であること
F_humanがlearned categoryと同一であること
```

また、今回のlearned category候補集合と`Γ_bridge`はfixture用であり、一般的な音楽学習モデルではない。

---

## ■ 8. 暫定結論

57では、54〜56で残した `ξ_base_to_learned_bridge` を、次の最小形で開いた。

```text
human-side response difference
  + external learned category candidates
  + Γ_base_to_learned_bridge_fixture
  → bridge candidate observed
```

ただし、この接続はlearned category生成でも、音楽解釈選択でもない。

```text
human-side response difference
  ≠ learned category generation
  ≠ selected musical interpretation
```

次に進むなら、同じhuman-side response differenceと同じexternal candidatesに対して、`Γ_bridge`を差し替えるとbridge候補が分岐するかを見る。
