```text

```

## ■ 4. Module差異

```text
音程Module:
  distinctive boundary = spelling-aware interval label and target-context separation
  origin candidate = B差 + Gamma差 + 音楽的固有性

和声機能Module:
  distinctive boundary = function annotation does not generate target by itself
  origin candidate = Gamma差 + controller差 + 音楽的固有性

リズム拍節Module:
  distinctive boundary = grid reopen changes candidate space without becoming realization
  origin candidate = B差 + 実装差 + 音楽的固有性

音高調律Module:
  distinctive boundary = physical relation and tuning category do not become pitch name
  origin candidate = B差 + Gamma差 + 音楽的固有性
```

## ■ 5. 禁止補完


## ■ 6. T2候補としての位置

```text
Core:
  最低限のT1代謝原理

T2候補:
  代謝を連続運用すると繰り返し現れる境界配置

Music:
  その境界配置が具体的な音楽差異を保持する場所
```

螺旋型再入循環は、現時点ではCoreではなくT2実行パターン候補として扱う。
