# 物理音高から音楽ラベルへの分岐｜構造抽出版

*対象：10〜13で観測した、物理関係・離散記述・綴り・文脈の分岐*  
*状態：DRAFT v0.1 / 音程Moduleの記述構造*

## ■ 0. 位置づけ

本書は、周波数関係が音楽ラベルや文脈的targetと同一ではないことを抽出する。targetの選択と具体音実現は、別の構造抽出版に置く。

## ■ 1. 物理関係から離散記述まで

```text
f1, f2
  ↓ Γ_ratio
frequency ratio
  ↓ Γ_cents
continuous interval coordinate
  ↓ Γ_12TET_round
12TET semitone category
```

純正五度の`3/2`と12TET上の五度`2^(7/12)`は物理的には異なる比だが、今回の離散化規則では同じ7半音へ写る。セント座標と12TET丸めは、物理対象そのものではなく比較・記述のための規則である。

## ■ 2. 綴りによる音程ラベル分岐

```text
same chromatic category
  + B_spelling
  ↓ Γ_generic
generic interval
  ↓ Γ_quality
interval label
```

同じ7半音でも、`C→G`は五度からP5へ、`C→A`は六度からd6へ分岐する。開始時点の物理音高対まで同一な`C4→G4`と`C4→A𝄫4`でも、綴り関係だけでラベルは分岐する。

## ■ 3. 文脈的targetとの境界

```text
spelling / interval label ─┐
contextual role ───────────┼→ target選択過程（本書の外）
learned tendency ──────────┘
                              ↓
                        selected target
                              ↓ Γ_motion
                      motion description
```

同一のトライトーン音高対でも、綴りによりA4／d5へ分岐する。代表的解決targetと運動方向は外部から与えられた候補に対する記述であり、音程ラベルから自動生成したものではない。

## ■ 4. 保持する非同一性

```text
frequency ratio ≠ cents coordinate
cents coordinate ≠ 12TET category
12TET semitone category ≠ interval label
same physical pitch pair ≠ same spelling relation
interval label ≠ contextual target
selected target ≠ concrete pitch realization
motion description ≠ target選択原理
```

## ■ 5. 確定接続・ξ・禁止補完

**確定接続**：物理比を連続座標と12TETカテゴリーへ写し、綴りを比較関係へ加えることでgeneric intervalと品質を分け、固定targetから運動記述を抽出できる。

**未解決ξ**：綴り・文脈・learned tendencyからtargetを生成する規則、様式差、文化差、知覚との接続、音楽ラベルが実際に果たす機能。

**禁止補完**：12TETカテゴリーから音程名を一意に出さない。音程ラベルからtargetを自動生成したことにしない。既知記述体系を人間の基層知覚や普遍法則と同一視しない。
