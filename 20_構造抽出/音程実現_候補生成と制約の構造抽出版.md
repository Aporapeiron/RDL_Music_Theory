# 音程実現｜候補生成と制約の構造抽出版

*対象：13〜15で観測した、目標音度から具体音への実現経路*  
*状態：DRAFT v0.1 / 音程Module固有の実現構造*

## ■ 0. 位置づけ

本書は、選択済みの目標音度から具体的な綴り付き音高へ至る現在の実現経路を抽出する。targetがなぜ選ばれたかという文脈・役割・learned tendency側の選択過程、再探索、動態Adapterは本書の外に置く。

## ■ 1. targetの注釈と実現の分離

```text
context + role assignment + learned tendency
  ↓ target選択過程（本書の外）
既選択のtarget degree
────────実現Module境界────────
  ↓
実現Module
  ↓
concrete target
  ↓
motion description
```

音程ラベルや`7→1`・`4→3`は具体音を一意に生成しない。文脈・役割・learned tendencyはtarget選択へ関与し得るが、本書では選択済みtarget degreeを実現Moduleへの入力として受け取る。具体音のオクターブ・声域・配置は後段の実現条件に残る。

## ■ 2. 実現経路

```text
target degree
  ↓ B_realization
candidate octaves / voice range
  ↓ Γ_spelling
generated spelled candidates
  ↓ B_range_projection
filtered candidates
  ↓ Γ_ordering
admissible voice pairs
  ↓ Γ_select
concrete target
```

`B_realization`は、候補生成の対象となるオクターブと各声部の範囲を宣言する実現空間の外枠である。`Γ_spelling`はまず宣言されたオクターブ上の綴り付き候補を生成し、`B_range_projection`がそれを各声部の実効範囲へ投影する。`Γ_select`は許容候補対から開始音との移動量を読む、今回の限定的な選択規則である。

## ■ 3. 結果分岐

```text
generated candidates
  ↓ B_range_projection
filtered candidates
  ├─ 片側がempty
  │    → constraint_no_candidate
  └─ 両側が残る
       ↓ Γ_ordering
       ├─ admissible pairs empty
       │    → no_admissible_candidate
       └─ pairs remain
            ↓ Γ_select
            → concrete target
```

候補消滅は単一の失敗ではない。声域投影で片側候補が消える場合と、両側候補が残った後に声部関係で候補対が消える場合を分けて保持する。`Γ_select`は許容候補対が残る場合だけ実行される。

## ■ 4. 保持する非同一性

```text
interval label ≠ target degree
target degree ≠ concrete pitch
generated candidates ≠ filtered candidates
filtered candidates ≠ admissible pairs
admissible pairs ≠ selected target
empty ≠ target一般の不在
```

同じ目標音度と同じ綴り候補生成でも、実現境界と関係制約により、具体音選択・片側候補消滅・許容対消滅へ分岐する。

## ■ 5. 確定接続・ξ・禁止補完

**確定接続**：音度から具体音への実現は、候補境界、綴り候補生成、声域投影、声部関係、選択を分けて観測できる。

**未解決ξ**：妥当な声域、上下関係の強さ、candidate empty後にどの条件を変えるか、制約緩和順序、様式・知覚・人間の選択原理。

**禁止補完**：音度遷移や音程ラベルから具体音を直接導かない。空結果を実現器全体の失敗としない。今回の`Γ_select`を一般的な作曲・演奏規則へ昇格しない。
