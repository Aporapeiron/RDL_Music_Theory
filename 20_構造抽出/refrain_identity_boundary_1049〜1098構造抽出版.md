# refrain identity boundary 1049〜1098 構造抽出版

## 位置づけ

999〜1048で再活性化された memory return が、どの条件で「同じものが戻った」と扱えるかを検査する境界である。

この構造は、リフレインを identical repetition へ還元せず、かつ文脈差を理由に new object へ切断しない。

## source_reentry

999〜1048の promoted memory を再入する。

```text
returned_label = C major continuation frame under altered B
previous_memory_state = compressed_latent_memory
return_state = reactivation_priority_candidate
```

## identity_request

refrain identity request は以下の崩壊を止める。

```text
identity ≠ label only
identity ≠ repetition
identity ≠ new object collapse
```

## cue_layer

同一性cueは以下である。

```text
motivic_anchor
harmonic_role
cadential_position
```

差異cueは以下である。

```text
B_shift
contextual_difference
surface_variation
```

cadential_position と surface_variation は、identity と difference の両方に関わる mixed cue として保持される。

## cue_guard

cue は判定材料であって、truth authority ではない。

```text
identity cue ≠ truth
difference cue ≠ breakage
variation ≠ deletion
```

## evaluation_layer

refrain identity は次の形で評価される。

```text
same_enough_as_refrain = True
identical_repetition = False
treated_as_new_object = False
selected = False
deleted = False
```

identity threshold rule:

```text
motivic_anchor_and_harmonic_role_survive_contextual_difference
```

difference retention rule:

```text
B_shift_and_contextual_difference_remain_inside_return
```

## boundary_view

リフレイン同一性は、以下の形で保持される。

```text
same with difference
```

これは、完全同一反復でも、完全別objectでもない。

## integrity

確認された整合条件は以下である。

```text
identity_not_label_only = True
refrain_identity_without_repetition = True
difference_retained_inside_return = True
return_not_new_object = True
no_selection_or_deletion = True
generated_mutation = False
```

## non_identity

1049〜1098で保持された非同一性は以下である。

```text
same enough ≠ identical
return ≠ new object
difference ≠ breakage
variation ≠ erasure
```

## music_subject

音楽的なリフレインは、コピーとして戻るのではなく、聞き手の記憶と現在文脈の差を同時に含んで戻る。

そのため、リフレインの同一性は「過去と同じである」だけでも、「過去とは別である」だけでも足りない。1049〜1098では、motivic anchor と harmonic role が持続し、B shift と contextual difference が内部差異として保持されるとき、same with difference としてのリフレイン同一性が成立すると観測した。

## 次の境界

1049〜1098の次の ξ は以下である。

```text
refrain_variation_lifecycle_stress
```

次は、同一性境界を通過したリフレインが、以後どのようにvariationとして展開・保持・再圧縮されるかを検査する。
