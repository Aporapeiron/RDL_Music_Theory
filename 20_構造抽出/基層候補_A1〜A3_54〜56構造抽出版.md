# 基層候補｜A1〜A3 54〜56構造抽出版

*対象：54〜56で確認した、既知基層参照からM_B^base候補へ送る共通検証形式*  
*状態：DRAFT v0.1 / 50_既知基層解釈参照からのA群初期構造抽出*

## ■ 0. 位置づけ

本書は、54〜56の最小検証列から、基層候補を扱うときの共通構造を抽出する。

54〜56では、既知研究の参照点をRDL基層M_Bとして直接採用しなかった。代わりに、既知参照点、`B_base`、`Γ_base`、人間側応答観測を分け、次の型でM_B^base候補だけを観測した。

```text
known base reference
  + B_base fixture
  + Γ_base fixture
  + human-side response observations
  ↓
M_B^base candidate observed
  ↓
confirmed M_Bではない
```

本書は、聴覚科学・神経科学・心理物理の一般理論を追加しない。54〜56のfixture列から見えた責務境界だけを圧縮する。

## ■ 1. 抽出された接続地図

```text
known base reference ───────────────┐
                                    │
physical input relation ────────────┤
  ├─ frequency difference           │
  ├─ physical Δf                    ├→ Γ_base comparison
  └─ temporal separation            │
                                    │
B_base fixture ─────────────────────┘
  ├─ stimulus form
  ├─ observation axis
  └─ measurement form
                                    ↓
human-side response observations
  ├─ frequency-selective response region
  ├─ behavioral discriminability
  └─ integrated / separated response
                                    ↓
M_B^base candidate observed
                                    │
                                    │ confirmed M_Bへ自動昇格しない
                                    │ learned musical categoryを生成しない
                                    ↓
ξ_base / 後続検証へ保持
```

この地図は、物理差から音楽カテゴリーが直に生えることを示さない。各段階には、既知参照点、B、Γ、fixture観測が挟まる。

## ■ 3. 保持する非同一性

54〜56から、次の非同一性を保持する。

```text
known base reference
  ≠ RDL基層M_B

physical input relation
  ≠ human-side response relation

F_device
  ≠ F_human

B_base fixture
  ≠ human基層の完成境界

Γ_base fixture
  ≠ 一般聴覚モデル
  ≠ 一般心理物理モデル

M_B^base candidate observed
  ≠ confirmed M_B^base

human-side response difference
  ≠ learned musical category
```

特に重要なのは、物理側で記述できる差と、人間側の応答差を同一視しないことである。54〜56で扱ったのは、物理差が人間系を通って応答差として観測される候補関係であり、音楽的カテゴリーの生成ではない。

## ■ 4. 依存関係として見えた形

fixture内では、M_B^base候補観測は次の関係として読むのが堅い。

```text
M_B^base candidate observation
  = C(known reference, physical input observations, human-side response observations; B_base, Γ_base)
```

ただし、これは一般式ではない。54ではfrequency-selective response、55ではbehavioral discriminability、56ではtemporal integration stateを応答軸として読んだ。

共通しているのは、応答軸をB_baseで限定し、比較の仕方をΓ_baseで限定したうえで、保存候補としてだけ観測する点である。

## ■ 5. 確定接続

**54**：A1をknown referenceとして受け取り、`B_base_frequency_response_fixture` と `Γ_frequency_response_comparison_fixture` のもとで、500Hzと2000Hzの入力差が `low_frequency_response_region` と `high_frequency_response_region` の応答差として観測されることを確認した。

**55**：A2をknown referenceとして受け取り、`B_base_frequency_discrimination_fixture` と `Γ_frequency_discriminability_comparison_fixture` のもとで、2Hzと40HzのΔf差が `low_discriminability` と `high_discriminability` の応答差として観測されることを確認した。

**56**：A3をknown referenceとして受け取り、`B_base_temporal_integration_fixture` と `Γ_temporal_integration_comparison_fixture` のもとで、8msと80msの時間間隔差が `integrated_response` と `separated_response` の応答差として観測されることを確認した。

いずれも、confirmed M_B^baseは生成していない。

## ■ 8. 現時点の読み方

54〜56の成果は、基層の完成ではなく、基層候補を検証へ送るための共通型を三回再現できたことである。

```text
known reference
  ≠ confirmed M_B^base

physical difference
  ≠ human-side response difference

human-side response difference
  ≠ learned musical category
```

ここまでで、基層とlearned層の境界は次のように見え始めている。

```text
physical state difference
  ↓
human transformation under B_base / Γ_base
  ↓
human-side response difference
  ↓
M_B^base candidate

──── ここで停止 ────

pitch / interval / rhythm / meter / tonality
  = learned側・中核音楽理論側との後続接続問題
```

この分離が保てる限り、後で実測データ、個体差、学習差、認知科学・脳物理を追加しても、既知参照点やfixture検証をCoreへ無制約に昇格せずに済む。
