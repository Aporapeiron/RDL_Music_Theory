## source_reentry

2699〜2748のconflict mediation after reactivationを再入する。

```text
reactivation conflict
→ conflict mediation
→ mediation outcome readiness
```

この段階で、mediationはcommitment cancellationでもreplacementでもresolutionでもないものとして保持済みである。

## readiness_request

mediationをoutcomeへ接続するためのreadiness requestを生成する。

ただしrequestは、outcome selectionでもexecutionでもfinal judgementでもない。

## readiness_layer

mediation種別ごとにreadinessを分ける。

```text
contextual conflict mediation
→ contextual outcome readiness

hearing shift conflict mediation
→ hearing shift outcome readiness

reference conflict mediation
→ reference outcome readiness
```

## readiness_condition_layer

readinessは、次の判断を可能にする条件として保持される。

```text
phrase context readiness
hearing weight readiness
reference scope readiness
```

これらは結果そのものではなく、次のoutcome attemptへ入るための準備条件である。

## partition_layer

readinessは三つの経路に分割される。

```text
contextual_readiness
hearing_shift_readiness
reference_readiness
```

分割はsolutionではない。

## readiness_view

readiness viewは、mediationを後段へ渡すための可視境界である。

ここでは、まだどのoutcomeが採用されるかは決まらない。

## bundle

bundleは以下を保持する。

```text
source_bundle
readiness_routes
contextual_readiness
hearing_shift_readiness
reference_readiness
stop_lines
```

## integrity

確認する条件:

```text
every mediation gets readiness route
readiness variety preserved
mediation conflict commitment traces preserved
readiness generated without selection
no execution judgement or resolution
```

## non_identity

```text
readiness ≠ outcome selection
readiness ≠ outcome execution
readiness ≠ resolution
```

この非同一性により、mediation後の緊張を即時結論へ潰さない。

## music_subject

音楽的には、これは「仲介された聴取が次の判断へ入れる状態」を表す。

文脈上の戻り、聞こえの重みの再聴取、参照軸の開放性が、それぞれ次のoutcome attemptの準備として保持される。

## summary

2749〜2798では、

```text
mediation
→ readiness
→ attempt boundary
```

のうち、readinessまでを検証した。
