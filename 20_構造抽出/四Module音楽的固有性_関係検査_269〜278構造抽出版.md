# 構造抽出：四Module音楽的固有性 関係検査

*対象：269〜278*  
*状態：DRAFT v0.1*

## ■ 1. 入力差異

```text
音程Module:
  spelling-aware interval label and target-context separation

和声機能Module:
  function annotation does not generate target by itself

リズム拍節Module:
  grid reopen changes candidate space without becoming realization

音高調律Module:
  physical relation and tuning category do not become pitch name
```

## ■ 2. 関係抽出地図

```text
Module固有差
  ↓
別Moduleの固有差とペアにする
  ↓
connection / interference / complement / non_identity を観測する
  ↓
B差 / Gamma差 / 実装差 / controller差の由来を比較する
  ↓
Music主語が保たれているか確認する
  ↓
次のModule対stress testへ渡す
```

## ■ 3. 関係種別

```text
connection:
  差異が別Module境界へ渡り得る

interference:
  差異どうしが干渉するが、同一軸へ潰せない

complement:
  差異が別Moduleの検査条件を補う

non_identity:
  似て見える差異を同一境界型へ統合しない

difference_origin_check:
  差異の由来を比較するが確定しない
```

## ■ 4. 確認した関係

```text
音高調律 → 音程:
  12TETカテゴリーは綴り境界へ渡るが音程名へ自動昇格しない

音程 → 和声機能:
  target/context分離はtarget候補境界へ渡るがfunction生成器にならない

和声機能 → リズム拍節:
  history依存target候補は履歴投影と比較できるが同じ履歴軸ではない

リズム拍節 → 和声機能:
  候補空間変更はtarget選択の時間的位置づけを補うが機能注釈ではない

音高調律 → 和声機能:
  物理比・調律カテゴリーは機能語彙ではない

リズム拍節 → 音程:
  grid境界と綴り境界はどちらもB差を持つが同じ境界型ではない
```

## ■ 5. 禁止補完

```text
connection
→ 自動昇格

interference
→ 共通軸への圧縮

complement
→ 統合Module要求

non_identity
→ 永久分離の確定

差異関係検査
→ Core接続診断の不要化
```

は行わない。

## ■ 7. 暫定結論

269〜278で、四Moduleの音楽的固有差は、共通骨格へ回収する対象ではなく、互いに接続・干渉・補完・非同一性を持つ関係網として扱えることを確認した。

これにより、螺旋型再入循環はMusic側で、差異を消す一般化装置ではなく、差異関係を読む比較装置としても機能する。
