# 音高・調律｜Module計画

*状態：DRAFT v0.1*

## 0. 目的

物理側で観測された周波数関係を、音楽理論上の音高・調律記述へ接続するためのModule境界を定める。

このModuleは、周波数比から音名・音程・調律体系を一意に導くものではない。物理観測層で得られる関係候補を受け取り、どの規則で離散化し、どの調律体系・表記体系へ渡すかを管理する。

```text
F_device / physical relation
  ↓
B_pitch_tuning + Γ_pitch_tuning
  ↓
M_B候補
  ↓
音程・綴り / 音階・調 / 和音Module
```

ここで扱うのは、基層知覚の完成モデルではない。人間の聞こえ、音高融合、協和感、うなり知覚、絶対音感・相対音感などは、未解決ξとして保持する。

## 1. 参照する既知音楽理論

- `30_既知音楽理論参照/02_音高と調律.md`
- `20_構造抽出/物理音高から音楽ラベルへの分岐構造抽出版.md`

既知音楽理論側では、次の語彙が参照される。

| 語彙 | このModuleでの扱い |
|---|---|
| 周波数 | 物理観測層から渡される入力値または関係値 |
| octave | `2:1`関係を音楽語彙として圧縮したラベル |
| pitch class | オクターブ差を捨象した離散分類 |
| 12平均律 | 連続周波数比を12分割カテゴリーへ写す規則 |
| 純正音程 | 小整数比を基準にする参照体系 |

これらはRDL Coreの基本概念ではなく、音楽Module内の既知記述体系として扱う。

```text
f1, f2
```

## 3. B

このModuleの境界候補を、以下に分ける。

| 境界 | 役割 |
|---|---|
| `B_wave_observation` | 物理観測窓、sample rate、観測格子位相 |
| `B_component_model` | 既知成分として `f1, f2` または `f_i(t)` を与えるか、未知波形推定へ進むか |
| `B_pitch_reference` | 基準周波数、基準音、基準オクターブの置き方 |
| `B_tuning_system` | 12TET、純正律、その他調律体系を選ぶ境界 |
| `B_discretization` | cents丸め、半音丸め、許容誤差、カテゴリー化方法 |
| `B_context_pass` | 後続Moduleへどの情報を渡すか |

重要なのは、物理観測境界と調律選択境界を混同しないことである。

```text
物理比がある
≠
調律体系が決まる
≠
音名が決まる
≠
人間にそう聞こえる
```

## 4. Γ

このModuleで使う関係抽出・変換規則の候補。

| Γ | 入力 | 出力 |
|---|---|---|
| `Γ_ratio` | `f1, f2` | `f2 / f1` |
| `Γ_ratio_time` | `f1(t), f2(t)` | 観測窓内の比保存・比破断 |
| `Γ_ratio_period` | 周波数比、最大分母、許容誤差 | 有理近似、共通周期候補 |
| `Γ_cents` | 周波数比 | cents座標 |
| `Γ_12TET_round` | cents座標 | 12TET半音カテゴリー |
| `Γ_tuning_compare` | 物理比、調律体系 | 調律上の偏差、近似度 |

これらのΓは、候補生成・比較・離散化の規則であり、音楽的意味や知覚判断そのものではない。

## 5. M_B候補

このModuleのM_B候補は、単一の音高ラベルではなく、境界内で保存または採用された関係の束として置く。

| M_B候補 | 内容 |
|---|---|
| `ratio_preserved` | 観測境界内で周波数比が保存される |
| `short_recurrence_candidate` | 有限時間内で短周期再帰候補が立つ |
| `ratio_break_detected` | 観測点で比破断を検出した |
| `continuous_interval_coordinate` | centsなどの連続座標へ写せる |
| `tuning_category_candidate` | 調律体系上の離散カテゴリー候補へ写せる |
| `tuning_deviation_record` | 純正比や12TET値からの偏差を記録できる |

この段階では、`octave`、`perfect fifth`、`C#`、`A4` などの音楽ラベルは未確定である。必要なら後続の音程・綴りModule、記譜Module、音階・調Moduleへ渡す。

## 6. 候補生成・制約・選択

候補生成は次の順序で分ける。

```text
物理観測候補
  ↓
関係候補
  ↓
連続座標候補
  ↓
調律体系上の離散候補
  ↓
後続Moduleへの受け渡し
```

### 候補生成

- `f1, f2` から比を生成する
- 比からcents座標を生成する
- cents座標から12TET半音カテゴリー候補を生成する
- 小整数比との近似関係を生成する
- 調律体系ごとの偏差を生成する

### 制約

- 観測時間窓
- sample rate
- 観測格子位相
- 許容誤差
- 最大分母
- 基準周波数
- 採用する調律体系

### 選択

このModule単独では、音楽ラベルの最終選択を行わない。

```text
tuning_category_candidate
  ↓
音程・綴りModule
音階・調Module
記譜Module
```

選択が必要な場合は、どの `B_context_pass` と後続Moduleが選択したのかを記録する。

## 7. 破断条件

このModuleが破断する、または次のξを残す条件。

- 同じ物理比が、複数の調律体系で異なる偏差・分類を持つ
- 同じ12TETカテゴリーが、綴りによって別の音程名へ分岐する
- 観測分解能が粗く、短時間の比破断を見落とす
- sample rateは同じでも、観測格子位相で破断検出が変わる
- 純正比と12TET近似の差をどこまで許容するかが決まらない
- 実音スペクトルの部分音が単一周波数比モデルへ収まらない
- 人間の知覚境界が物理観測境界と一致しない

禁止する短絡は次の通り。

```text
2:1 = octaveとして常に確定
3:2 = perfect fifthとして常に確定
12TET 7半音 = P5として常に確定
物理的近似度 = 音楽的採用理由
F_device = F_human
```

## 8. 未解決ξ

現時点で残す未解決領域。

- 未知波形から `f1, f2` または部分音構造を推定する方法
- 実音のスペクトル、倍音、非整数倍音、ノイズ成分
- 振幅、包絡、attack/decay、音色が音高候補に与える影響
- うなり、協和・不協和、融合、分離の知覚条件
- 調律体系の選択原理
- 歴史的・文化的・楽器的な調律制約
- 基準音・基準ピッチの決定過程
- `F_device` と `F_human` の差分
- 基層知覚として何を仮設できるか

これらは、現段階では基層へ直接書き込まず、物理層とlearned層を詰めた後に残差として回収する。

## 9. 次の最小検証

次に必要な最小検証は、音高・調律Moduleから音程・綴りModuleへの受け渡しである。

```text
同じ物理比 / 同じ12TETカテゴリー
  ↓
調律偏差record
  ↓
綴り境界B_spelling
  ↓
異なる音程ラベル候補
```

最小ケースは次の二つ。

| ケース | 検証したいこと |
|---|---|
| `3/2` と `2^(7/12)` | 純正比と12TET近似が同じ7半音カテゴリーへ写るが、偏差recordは残る |
| 同じ7半音カテゴリー | `C→G` と `C→A𝄫` が別の音程ラベルへ分岐する |

この検証により、音高・調律Moduleの出力が音程名を直接決めるのではなく、後続Moduleへ渡される候補束であることを確認する。

## 10. 現時点の短縮式

```text
音高・調律Moduleは、
物理周波数関係を
連続座標・調律体系上の離散候補・偏差recordへ写す。

ただし、
音名・音程名・文脈target・人間の聞こえは
ここでは確定しない。
```
