# 中核音楽理論｜計画表

*役割：物理側の観測層と既知音楽理論参照を受け取り、RDL音楽の中核Moduleとして何を検証・構造化するかを管理する。*
*状態：DRAFT v0.1*

## ■ 0. 位置づけ

本フォルダーは、既知音楽理論の辞書ではない。

```text
30_既知音楽理論参照
  = 既存体系ではどう記述されるか

40_中核音楽理論
  = RDL音楽として何をModule化し、どの順で検証するか
```

中核音楽理論は、物理側の観測層と基層知覚条件を飛び越えて直接「人間の聞こえ」を確定しない。

```text
F_device / physical relation
  ↓
既知音楽理論参照
  ↓
RDL音楽Module候補
  ↓
未解決ξとして残る基層・文脈・選択原理
```

## ■ 1. 基本方針

- 既知音楽理論をRDL Coreへ昇格しない
- 音楽ラベルを物理比から一意に導かない
- learned構造とcontext構造を混同しない
- 候補生成、制約、選択、実現、履歴を分ける
- 基層知覚は直接モデル化せず、物理層とlearned層の残差から後で仮設する
- 各Moduleは `B / Γ / M_B候補 / ξ / 破断条件` を持つ

## ■ 5. 破断条件

- 既知音楽理論の分類をRDL側の結論として扱っている
- 物理比から音楽ラベルを一意に導いている
- learned構造を人間の普遍知覚として扱っている
- contextのtarget選択を音程ラベルから自動生成している
- Module固有の候補生成器やcontrollerをCoreへ昇格している
- 基層知覚を未検証のまま完成モデルとして置いている
