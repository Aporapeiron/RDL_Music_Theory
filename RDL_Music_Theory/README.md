# RDL Music Theory

RDL音楽理論の検討・設計・検証を行うリポジトリ。

## 初期構成

```text
00_RDL音楽理論.md
    入口・全体構造・運用方針

01_RDL音楽_Core.md
    音楽領域で共通して使う最小の状態記述と操作

02_RDL音楽_文書地図.md
    文書の役割・依存関係・分岐条件
```

具体的な調律・和声・旋律・リズム・楽式などは、Coreへ集積せず、必要になった時点で検証結果とともに分岐させる。
