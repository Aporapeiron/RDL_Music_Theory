# 50_T2_Fixtures

Music入力と、T1形成経路・T2汎用検査道具候補を接続し、Music出力へ戻すfixtureを置く領域。

旧名は `T2_Fixtures` のまま保持するが、新T0/T1基準ではここを「T2本体」とは扱わない。

責務:

```text
Music Probeの具体入力を置く
Music固有のSelection基準を明示する
許容損失・停止線を記録する
汎用検査道具候補がMusic対象でどう働くかを確認する
Music出力へ戻る接続条件を保持する
```

ここはMusic固有理論でもT2本体でもなく、Music設計と汎用検査道具候補の接続検査を保持する。
